# CLAUDE.md

Guidance for engineering agents working in `onesyue/yueboard`, an independent
repository in the Yue.to workspace. Read `../CLAUDE.md` for workspace rules.

## Purpose and compatibility

**Native Go control plane for Yue.to.** The strangler rewrite originated from
Xboard, but production Xboard was retired on 2026-07-23. There is no PHP process,
container or fallback. PostgreSQL uses native names such as `users`, `orders`,
`plugins` and `settings`. Released clients retain the compatible HTTP wire
contract in `docs/api-contract.md`.

1. **Preserve client contracts.** The v1 envelope remains
   `{status,message,data,error}` through `internal/platform/apiresp` where that
   contract applies. Authentication rejection must be HTTP 403 with non-HTML
   JSON: clients use non-HTML 401/403 responses to detect logout. Check the
   contract's endpoint-specific exceptions before changing responses.
2. **Never restore the retired panel fallback.** `internal/platform/fallback`
   was deleted and legacy fallback environment variables are unsupported.
   Unmatched routes use the anti-GFW decoy/404 behavior. Implement missing
   business endpoints natively with contract coverage.

## PostgreSQL integration tests

Integration tests use in-process `httptest` servers and a real PostgreSQL schema
fixture derived from production `pg_dump`. They catch execution-only errors such
as ambiguous columns, unused INSERT parameters and pgx fatal-close on mismatched
types. Fixtures include PG17/18 `transaction_timeout`, requiring PostgreSQL 17+.
The actual CI environment uses PostgreSQL 18.

```sh
YUEBOARD_TEST_DATABASE_URL=<redacted-local-dsn> \
  go test -tags integration -v ./test/integration/...
```

**That command does not cover the module integration suites.** `nodesync`,
`emby`, `handoff`, `deviceidentity`, `user`, `referencelock`, `order`, `db` and
`nativeproto` require their own coverage. Missing DSNs can call `t.Skip` while
`go test` still prints `ok`; inspect actual verbose run/pass/skip events.
`TestClonedReportOutboxCannotDoubleBill` and the billing-report cases are among
the critical tests outside `./test/integration/`.

The public central runner owns the current sequencing. Run domain fixtures on
a fresh PostgreSQL service, the clean-PG gate in an independent fresh database
of the same cluster, module suites serially, then full db/nativeproto migrations
and production-scale cases. Earlier migrations can create roles that hide a
fixture-initialization defect. `deviceidentity` and `nodesync` rebuild `public`
and must follow consumers of the full fixture.

For a targeted module run against an explicitly disposable database:

```sh
YUEBOARD_TRAFFIC_TEST_DATABASE_URL=<redacted-local-dsn> \
YUEBOARD_TEST_DATABASE_URL=<redacted-local-dsn> \
YUEBOARD_EMAILVERIFY_TEST_DATABASE_URL=<redacted-local-dsn> \
YUEBOARD_TEST_FIXTURES=$PWD/test/fixtures \
YUEBOARD_MIGRATION_TEST_ALLOW_RESET=YES_I_UNDERSTAND_THIS_DATABASE_IS_DISPOSABLE \
  go test -count=1 -p 1 -tags integration -v \
    ./internal/modules/user ./internal/platform/referencelock \
    ./internal/modules/order ./internal/modules/emby ./internal/modules/handoff \
    ./internal/platform/deviceidentity ./internal/modules/nodesync
```

`user` and `referencelock` were missing from all commands before 2026-09-21.
`nativeproto` uses the migration DSN. `internal/platform/toolchain`'s
`TestEveryIntegrationPackageRunsInCI` detects integration packages omitted from
CI orchestration. A successful package line alone is insufficient.

Migration tests need separate explicit inputs:

```sh
YUEBOARD_MIGRATION_TEST_DATABASE_URL=<redacted-local-dsn> \
YUEBOARD_MIGRATION_TEST_ALLOW_RESET=YES_I_UNDERSTAND_THIS_DATABASE_IS_DISPOSABLE \
YUEBOARD_MIGRATION_TEST_PRODUCTION_SCALE=1 \
  go test -count=1 -tags integration -v ./internal/platform/db ./internal/platform/nativeproto
```

These tests are destructive (`DROP SCHEMA public CASCADE`). Use the native
runner's ordering or a separate disposable database, never production.
`TestNativeMigrationsProductionScaleOnPostgres` executes the complete goose
chain from zero, including the approximately 1.1-million-row scale fixture.
`TestNativeMigrationsOnPostgres` checks a selected chain's ACL, trigger and
catalog semantics. An ACL migration requires updated semantic assertions, not
just adding its filename. The 2026-08-12 `emby_launch_audit` permission failure
exposed the cost of skipped real PostgreSQL migration tests.

The shared integration account/server also shares the checkout rate limiter.
Production defaults to ten checkouts per user per minute. `TestMain` defaults
`YUEBOARD_CHECKOUT_RATE_LIMIT_PER_MINUTE` to `10000` before `bootHandler`, unless
the caller sets it, to prevent unrelated later cases receiving 429. Keep the
production default protected by `checkout_rate_limit_default_test.go`.
`t.Setenv` inside a test cannot reconfigure a limiter already read by `order.New`.

Use workspace `../scripts/run-yueboard-pg18-gauntlet.sh` when no suitable local
PostgreSQL is running. It uses disposable `postgres:18.6-alpine`, a pool size of
four and automatic container cleanup. Do not run heavy tests on the bastion:
it has been CPU-steal constrained since the dated 2026-10-11 observation.
Clean up disposable containers, binaries and accounts. Production database
inspection remains read-only; never use it for destructive tests.

## Architecture

The backend is a modular monolith using chi and pgx/pgxpool, with no ORM.

- `internal/modules/<mod>/`: business domains with `New(pool, st, ...)` and
  `Routes(chi.Router)`. Do not import another business module.
- `internal/platform/<pkg>/`: shared `db`, `auth`, `settings`, `apiresp`, `mail`,
  `verify`, `metrics`, `antigfw`, `resource` and `apptime` infrastructure.
- `internal/server/server.go`: composition only. Middleware order matters:
  `antigfw.Harden` first (`Server: nginx`), then `RealIP`,
  `antigfw.TarpitMiddleware`, RequestID, Recoverer and metrics.
- `cmd/yueboard/main.go`: constructs `server.Deps`. Wire new modules here and
  mirror the wiring in `test/integration/harness_test.go::bootHandler`.
  `deps.Extra` is for `/api`; `deps.Root` is for root endpoints.

User modules mount only under `/api/v1/*`, using relative paths such as
`/user/emby` in `Routes`. `/api/v2/*` contains the admin group and subscription
aliases, not user APIs. `TestAdminRoutesGuarded` protects that boundary after
stale dual-prefix guidance was corrected on 2026-09-05.

Admin traffic uses `/api/v2/{secure_path}/*` inside the `/api` group, never the
root group. The production secure path exists only in settings; do not record
it in source. Subscription delivery and node synchronization use `deps.Root`.
For explicitly parallel development, each worker owns its package; the main
integrator alone wires `main.go` and `harness_test.go`.

## Schema and generated data access

- Goose migrations live in `internal/platform/db/migrations/*.sql` and are
  embedded. Run `yueboard migrate up|down|status`; service startup does not
  auto-migrate. `adoptBaseline` recognizes existing `users` and stamps version
  1 without rerunning 00001. Actual column conversion begins at 00002.
- Named SQL in `internal/modules/<mod>/queries/` generates that module's `store/`
  via sqlc. Never hand-edit generated code or import another module's store.
  Shared `plugins`, `settings` and `personal_access_tokens` stores belong in
  the corresponding platform package.
- Unmarked migrations must expand: add tables, nullable/defaulted columns,
  indexes, functions or grants. `DROP TABLE|COLUMN|FUNCTION`, `RENAME`,
  `ALTER … TYPE` and `SET NOT NULL` without a default require
  `-- +yue contract-of: NNNNN` at the Up header, with NNNNN no greater than the
  deployed `schema-compat.txt` floor. Advance that floor only after actual
  successful deployment. `make check-migrations`, PG18 integration and runtime
  `migrate up` enforce the same rule. The exemption set is capped at 83.
- `test/fixtures/schema.sql` is the shared real-DDL source for sqlc and
  integration. Update it with column migrations. `make generate` pins sqlc;
  `make check-generated` rejects regeneration drift. Query native nullable
  timestamps, preserve NULL through pgtype and convert epochs at response time.
- Keep `resource.PlanResource`, `apptime` (Asia/Shanghai), the v1 envelope and
  403-JSON logout semantics, and anti-GFW nginx-404 behavior. These are client
  and domain contracts, not disposable PHP migration leftovers. A future owned
  `/api/v3` requires coordinated client/token migration, separate from schema work.

## Incident lessons

- pgx v5 `rows.Scan` type mismatches call `rows.fatal()` and silently truncate
  the rowset. Match real column types, including nullable values and floating
  monetary columns. Real-schema integration is essential.
- Plugin configuration is JSON text in `plugins.config`, not `settings`.
  `invitealias`/`emby` use `SELECT is_enabled, config FROM plugins WHERE code=$1`
  with a 60-second process cache. Preserve permissive legacy bool/integer forms
  such as `true`, `1`, `"1"` and `"3"` where the existing contract requires them.
- PHP `preg_replace` without `/u` operates on bytes; Go regexp operates on runes.
  `emby.toUsername` uses a byte loop for compatibility. Derived keys/hashes must
  preserve the original `config('app.key')` string, including `base64:`. Compare
  PHP `hash_hmac` output and verify the real external-service consumer.
- Prefix package-level identifiers within modules (`ce`, `ia`, `emby`, etc.) to
  avoid cross-file and future package-merging collisions.

- `ship.sh` only chains the audited per-step scripts, scraping digests from the *promote* step's log

## Cross-repo coupling that isn't visible in any single repo

- **Subscription generation is a contract between yueboard and every client family.** `yueboard/internal/modules/subscribe/` renders Clash Meta, Surge, Loon, Quantumult X, Surfboard, sing-box, and general links from native templates. There is no `?yl=1` or device-specific server branch. When one client fails, render its exact User-Agent and compare fields against a working renderer before changing the fleet.
- **The server template is the YueLink source of truth.** YueLink no longer inlines `GeoIP.dat`/`GeoSite.dat`; it seeds the exact bundled `.mrs` set and preserves server routing. Keep client transforms bounded to compatibility defaults, and use the reference clients to justify any divergence.
- **The schema is native; remaining cross-service reads are explicit migration debt.** Tables use native names, `numeric` amounts, `jsonb`, and `timestamptz`. YueBoard owns panel-domain writes. Any temporary YueOps read must be catalogued and moved behind a scoped native internal API before its DB credential is removed.
- **Panel↔node control is ConnectRPC only.** The protobuf contract is shared by yueboard and yue-node. Every physical host must use a machine-scoped credential and exact assignment; a fleet-wide token, REST polling, or WS push is a migration regression.
- **🚨 Never rebuild a node by copying another node's `/home/yue-node` wholesale.** The runtime tree
  contains `node-*/data/report-outbox`, which is the machine's **billing identity**. Cloning it either
  double-bills or wedges the node forever on `report sequence gap`, which has no recovery path. This
  has now happened twice (2026-08-01, 2026-08-11). **Wipe `node-*/data/report-outbox` before first
  start** — the in-code owner guard only protects hosts already running yue-node `4bf9ada` or newer.
  📎 Full provisioning / cloning / retiring / hard-delete procedure: the **`node-lifecycle`** skill.

## Release / CI: what is true in every session

Four things must name the same commit: the reviewed **pin**, the source repo **HEAD**, the
**promoted** image, and what **production** actually runs. `release-state.py` prints all four.
- **2026-10-12: SSH authority is ACTIVE.** Every new yueops revision needs auto-pull + `make-release-root.sh
  --strict` + `scripts/ship-sshd-authority.py --apply` before Ops/panel deploys or A/B publishing (ship.sh chains them).
- **2026-10-11: bastion is CPU-steal-bound** (60–78%): no heavy tests there; check `vmstat` st first. 📎 `release-chain`.

**Before pushing `yueboard/master`, establish its effect on the active release.**
Promotion requires default-branch ancestry, inputs identical to HEAD and a candidate
not older than `:latest`. A changed input can invalidate a running release.
When inputs change, the integration owner must complete these steps:

1. Read the revision labels off the **running production** panel image and node fleet, then run
   `scripts/converge-yueboard-release-pin.py --from-head --deployed-board-revision <prod-board>
   --deployed-node-revision <prod-node>`. Both are explicit because reviewed candidates may never
   have been deployed. It updates yueto-ci's two copies atomically and **derives** the schema
   floor from `git show <rev>:schema-floor.txt`; since P2 §4 A3 it no longer writes yueops.
2. Coordinate the required rebuild and panel deployment with the release owner.
   The desired state yueops deploys from is the **signed** root `release.yaml`
   (ship.sh writes + seals it; no pin is committed back into yueops). 📎 `release-chain`.

Promote, `release-state.py` and the schema-migrator contract accept a descendant
with unchanged native image inputs and the same schema floor while retaining the
reviewed pin. Use the actual input comparator: a Markdown or test filename alone
does not establish equivalence. Changed or unknown inputs retain the normal pin
convergence and release requirements. Preserve each active writer's source custody.

job annotation decisive) before reading any red run; the local `gauntlet.sh` is the real gate either way.

# Guard authoring (Yue.to)

The expensive failure is a green guard protecting nothing. The linked incident examples
occurred in actual production work.

Apply the checklist to the guard's actual inputs, dependencies and claimed
coverage. Running an existing check does not require redesigning it. A changed
assertion, scan boundary or success/failure classification does require this skill.
For import/fixture leakage, load [test isolation](references/test-isolation.md)
first; use the guard checklist only if guard coverage changes.

Before adding an invariant, establish which consumer needs it and check its
actual semantics. Challenge it with one realistic counterexample at that boundary:
subprocess execution for locks, a write failure for persistence, or raw single-target
output for collectors. Matching strings or unrelated runner-image labels cannot
establish those properties. Reuse the recorded interpreter/image, user and mounts;
classify failures as startup, collection or assertion before editing product code.

## Establish three facts before accepting green

1. Did this run reach the target? Zero executions is not a pass.

3. Is the guarded layer the layer users and production actually encounter?

func (m *Module) AbuseRound(ctx context.Context) (AbuseReport, error) {
	var rep AbuseReport
	now := m.now()
	modes, invalid, err := fairuse.LoadModes(ctx, m.st)
	if err != nil {
		// A partial read cannot authorize a fresh enforcement decision.
		modes = fairuse.Modes{}
		metrics.Event("usagepolicy.mode_unreadable")
		slog.Warn("usagepolicy: 模式读取失败，本轮按 shadow 处理", "err", err)
	}
	for range invalid {
		metrics.Event("usagepolicy.mode_invalid")
	}
	if n, e := m.correctReplayedEscalations(ctx); e != nil {
		rep.Errors++
		slog.Error("usagepolicy: historical escalation correction failed", "err", e)
	} else {
		rep.Corrected = n
	}
	if n, e := m.correctRepeatedLowThrottles(ctx); e != nil {
		rep.Errors++
		slog.Error("usagepolicy: repeated low-confidence throttle correction failed", "err", e)
	} else {
		rep.Corrected += n
	}

	// Resolve source coverage before replaying pending resets. Merely loading
	// the configured enforce mode is insufficient during a cold history window
	// or a foundation rollback. Collect reuses this exact exclusion snapshot.
	ex := m.exclusion(ctx)
	modes = effectiveModes(modes, ex)
	if n, e := m.retryPendingResets(ctx, modes); e != nil {
		rep.Errors++
		slog.Error("usagepolicy: retry resets failed", "err", e)
	} else {
		rep.Retried = n
	}
	dets, derr := m.collect(ctx, now, modes, ex)
	if derr != nil {
		rep.Errors++
		slog.Error("usagepolicy: 取信号失败", "err", derr)
	}
	rep.Detections = len(dets)
	for _, d := range dets {
		mode := modes.Of(string(d.Kind))
		if mode == fairuse.ModeOff {
			continue
		}
		if mode == fairuse.ModeEnforce && d.ShadowOnly != "" {
			// 证据不足以授权处置（如剔除集不完整）：只记 shadow 账。
			mode = fairuse.ModeShadow
			metrics.Event("usagepolicy.enforce_withheld." + string(d.Kind))
		}
		recorded, applied, err := m.decide(ctx, d, mode, now)
		if err != nil {
			rep.Errors++
			slog.Error("usagepolicy: 处置失败", "user_id", d.UserID, "kind", d.Kind, "err", err)
			continue
		}
		if recorded {
			rep.Recorded++
		}
		if applied {
			rep.Applied++
		}
	}

	if n, err := m.expireStrikes(ctx, now); err != nil {
		rep.Errors++
		slog.Error("usagepolicy: 到期解除失败", "err", err)
	} else {
		rep.Expired = n
	}
	if n, err := m.restoreExpiredRestrictions(ctx); err != nil {
		rep.Errors++
		slog.Error("usagepolicy: 恢复到期限速失败", "err", err)
	} else {
		rep.Restored = n
	}
	if n, err := m.reconcileRestrictions(ctx); err != nil {
		rep.Errors++
		slog.Error("usagepolicy: 限速对账失败", "err", err)
	} else {
		rep.Reconciled = n
	}

	}

// PresenceSlotSQL inlines public.presence_day_slot(at) (00136): the UTC day
// number of at modulo 16. Readers inline it instead of calling the function so
// the session readers keep needing nothing beyond SELECT; the integration
// suite proves it equals the function for every instant it samples.
func PresenceSlotSQL(at string) string {
	return "(((floor(extract(epoch FROM " + at + ") / 86400)::bigint % 16) + 16) % 16)::smallint"
}

// presenceSlotsSQL is the ring-pruning predicate for a window ending at the
// clock expression now: the UTC days of each offset (callers pass the window's
// days plus tomorrow, for writer clock skew).
func presenceSlotsSQL(now string, offsets ...string) string {
	slots := make([]string, len(offsets))
	for i, offset := range offsets {
		slots[i] = PresenceSlotSQL(strings.TrimSpace(now + " " + offset))
	}
	return "day_slot IN (" + strings.Join(slots, ", ") + ")"
}

			}

			applied = changed
		}
	}

// DetectCounters 判转售 / BT / 邮件 / 扫描。
func DetectCounters(s CounterSignals) []Detection {

	// Resell throttling requires both strong limits: concurrent streams and destinations.
	// One strong signal alone is observation only. Upload skew, hosting origins, and moderate fanout
	// cannot authorize sanctions alone, together, or alongside only one strong signal.
	// Multiple weak signals retain shadow evidence without sending a notice.
	var strong, weak []string
	if s.ConcurrentPeak >= ResellConcurrentPeak {
		strong = append(strong, "concurrent_peak")
	}
	if s.DistinctDestinations >= ResellDistinctDestinations {
		strong = append(strong, "distinct_destinations")
	}
	if s.FanoutPeak >= ResellFanoutPerMinute && s.FanoutPeak < ScanFanoutLow {
		weak = append(weak, "fanout")
	}
	if s.Up7d > s.Down7d && s.Up7d >= UploadSkewMinBytes {
		weak = append(weak, "upload_skew_7d")
	}
	if s.HostingSessions >= HostingSessionsPerDay {
		weak = append(weak, "hosting_asn_sources")
	}
	signals := append(append([]string{}, strong...), weak...)
	if len(signals) > 0 {
		conf := ConfidenceLow
		shadow := ""
		if len(strong) >= 2 {
			conf = ConfidenceHigh
		} else if len(strong) == 0 {
			shadow = "resell_ambiguous"
		}
		out = append(out, Detection{UserID: s.UserID, Kind: KindResell, Confidence: conf, Day: day, ShadowOnly: shadow,
			Evidence: map[string]any{
				"signals":                 signals,
				"concurrent_peak":         s.ConcurrentPeak,
				"distinct_destinations":   s.DistinctDestinations,
				"distinct_is_upper_bound": true,
				"fanout_per_minute_peak":  s.FanoutPeak,
				"up_7d_bytes":             s.Up7d,
				"down_7d_bytes":           s.Down7d,
				"hosting_sessions_24h":    s.HostingSessions,
			}})
	}

		confidence, shadow := ConfidenceLow, ""
		if len(strong) == 1 {
			confidence = ConfidenceHigh
		} else if len(strong) >= 2 {
			// Resell already owns the sanction for this user/day.
			shadow = "resell_high"
		}

				"strong_signals":   append([]string{}, strong...),
				"concurrent_peak":  s.ConcurrentPeak, "concurrent_threshold": ResellConcurrentPeak,
				"distinct_destinations": s.DistinctDestinations, "destinations_threshold": ResellDistinctDestinations,
				"distinct_is_upper_bound": true,
			}})
	}

		if c == ConfidenceHigh && !ok {
			return ConfidenceLow
		}
		return c
	}

			Evidence: map[string]any{"bt_hits": s.BTHits, "high_threshold": BTHitsHigh, "fanout_peak": s.FanoutPeak, "concurrent_peak": s.ConcurrentPeak}})

type ReplayQuerier interface {
	Query(ctx context.Context, sql string, args ...any) (pgx.Rows, error)
	QueryRow(ctx context.Context, sql string, args ...any) pgx.Row
}

// replayKey 是 (用户, 类型, UTC 日)。
type replayKey struct {
	uid  int64
	kind Kind
	day  string
}

// replayOld 是一组历史记录（同 key 不同 mode 合并，取最高置信度）。
type replayOld struct {
	high        bool
	sanctioning bool
}

// replayNew 是一个新判定。
type replayNew struct {
	high        bool
	sanctioning bool
}

// ShadowReplay 跑回放。q 必须是只读事务（调用方保证）。
func (m *Module) ShadowReplay(ctx context.Context, q ReplayQuerier, opts ReplayOptions) (ReplayReport, error) {
	from := opts.From.UTC().Truncate(24 * time.Hour)
	to := opts.To.UTC().Truncate(24 * time.Hour)
	now := m.now().UTC()
	if to.Before(from) {
		return ReplayReport{}, fmt.Errorf("to %s is before from %s", to.Format(time.DateOnly), from.Format(time.DateOnly))
	}
	if days := int(to.Sub(from)/(24*time.Hour)) + 1; days > ReplayMaxDays {
		return ReplayReport{}, fmt.Errorf("window is %d days, at most %d", days, ReplayMaxDays)
	}
	if to.After(now) {
		to = now.Truncate(24 * time.Hour)
	}
	rep := ReplayReport{From: from.Format(time.DateOnly), To: to.Format(time.DateOnly), RulesVersion: RulesVersion,
		EvaluatedAt: now.Unix(), Caveats: replayCaveats()}

	// 剔除集：现在的 peer_ip ∪ 库存（库存从同一只读事务读）。
	var peerKeys []string
	peerOK := false
	if m.fleet != nil {
		peerKeys, peerOK = m.fleet.Keys(ctx)
	}
	raw, invErr := fleetegress.LoadInventory(ctx, q)
	history, historyErr := fleetegress.LoadHistory(ctx, q, now)
	ex := newExclusionState(fleetegress.ForReleasePhase(fleetegress.WithHistory(fleetegress.Assess(peerKeys, peerOK, raw, invErr, now), history, historyErr, now)), ipfingerprint.Secret())
	rep.Exclusion = ReplayExclusion{Complete: ex.usable(), Reason: ex.reason(), Keys: len(ex.Keys), PeerKeys: ex.PeerKeys,
		InventoryKeys: ex.InventoryKeys, Relays: ex.Relays, Directs: ex.Directs}
	if !ex.secretOK {
		rep.Caveats = append(rep.Caveats, "ip fingerprint secret unavailable: sharing could not exclude any fleet source")
	}

	old, err := replayLoadOld(ctx, q, from, to)
	if err != nil {
		return rep, fmt.Errorf("old strikes: %w", err)
	}
	dets, err := m.replayDetect(ctx, q, from, to, now, ex)
	if err != nil {
		return rep, err
	}
	fresh := map[replayKey]replayNew{}
	for _, d := range dets {
		k := replayKey{d.UserID, d.Kind, d.Day.UTC().Format(time.DateOnly)}
		n := fresh[k]
		n.high = n.high || d.Confidence == ConfidenceHigh
		n.sanctioning = n.sanctioning || (d.Confidence == ConfidenceHigh && d.ShadowOnly == "")
		fresh[k] = n
	}
	rep.Old, rep.New, rep.Diff = diffReplay(old, fresh, opts.Sample)
	return rep, nil
}

func replayCaveats() []string {
	return []string{
		"sharing: two evaluation points per day (00:10 and 24:00 UTC, capped at now) instead of every 10 minutes; device limit uses the current plan/account value",
		"fleet exclusion includes native writer observations from the last 48h; missing or warming coverage withholds enforcement. Older replay days remain approximate: history is retained 72h and current device limits/peer snapshot are used",
		"leak: subscription_fetch_origins keeps only 24-48h, so leak is replayed for today only",
		"counter kinds read user_abuse_daily (30-day retention); presence_session_log keeps 14 days, so sharing/hosting evidence older than that is absent",
		"old side merges shadow and enforce rows of the same user/kind/day, taking the highest confidence",
	}
}

func replayLoadOld(ctx context.Context, q ReplayQuerier, from, to time.Time) (map[replayKey]replayOld, error) {
	rows, err := q.Query(ctx, replayOldSQL, from, to)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	out := map[replayKey]replayOld{}
	for rows.Next() {
		var uid int64
		var kind, day, conf, mode, action string
		var applied bool
		if err := rows.Scan(&uid, &kind, &day, &conf, &mode, &action, &applied); err != nil {
			return nil, err
		}
		k := replayKey{uid, Kind(kind), day}
		o := out[k]
		o.high = o.high || conf == string(ConfidenceHigh)
		o.sanctioning = o.sanctioning || (mode == "enforce" && applied && action != string(ActionNotice))
		out[k] = o
	}
	return out, rows.Err()
}

func replaySharingSQL() string {
	return mustReplaceAll(sharingSQL(), map[string]string{

		"     AND country IS NOT NULL": "     AND started_at < $3::timestamptz\n     AND country IS NOT NULL",
	})
}

// mustReplaceAll 替换每一个片段；任一片段找不到就 panic——生产查询改了形状时回放
// 必须当场失败，而不是悄悄换成另一份判据。
func mustReplaceAll(s string, repl map[string]string) string {
	keys := make([]string, 0, len(repl))
	for k := range repl {
		keys = append(keys, k)
	}
	slices.Sort(keys)
	for _, old := range keys {
		if !strings.Contains(s, old) {
			panic("usagepolicy replay: production query no longer contains " + old)
		}
		s = strings.ReplaceAll(s, old, repl[old])
	}
	return s
}

func (m *Module) replayDetect(ctx context.Context, q ReplayQuerier, from, to, now time.Time, ex exclusionState) ([]Detection, error) {
	var out []Detection
	hostingOn := len(m.hostingASNs) > 0 && ex.usable()
	hosting := map[string]map[int64]int64{}
	if hostingOn {
		for day := from; !day.After(to); day = day.Add(24 * time.Hour) {
			at := day.Add(24 * time.Hour)
			if at.After(now) {
				at = now
			}
			counts := map[int64]int64{}
			rows, err := q.Query(ctx, replayHostingSQL, m.hostingASNs, ex.digests, ipfingerprint.CurrentVersion, at)
			if err != nil {
				return nil, fmt.Errorf("hosting: %w", err)
			}
			for rows.Next() {
				var uid, n int64
				if err := rows.Scan(&uid, &n); err != nil {
					rows.Close()
					return nil, err
				}
				counts[uid] = n
			}
			rows.Close()
			if err := rows.Err(); err != nil {
				return nil, err
			}
			hosting[day.Format(time.DateOnly)] = counts
		}
	}

	rows, err := q.Query(ctx, replayCountersSQL, from, to)
	if err != nil {
		return nil, fmt.Errorf("counters: %w", err)
	}
	for rows.Next() {
		var s CounterSignals
		var cp, fp int32
		var regs []byte
		if err := rows.Scan(&s.UserID, &s.Day, &cp, &fp, &s.BTHits, &s.MailAttempts, &regs, &s.Up7d, &s.Down7d); err != nil {
			rows.Close()
			return nil, err
		}
		s.ConcurrentPeak, s.FanoutPeak = int64(cp), int64(fp)
		s.DistinctDestinations = estimateRegisters(regs)
		s.HostingSessions = -1
		if hostingOn {
			s.HostingSessions = hosting[s.Day.UTC().Format(time.DateOnly)][s.UserID]
		}
		for _, d := range DetectCounters(s) {
			capForExclusion(&d, ex)
			out = append(out, d)
		}
	}
	rows.Close()
	if err := rows.Err(); err != nil {
		return nil, err
	}

	}

func replaceOnce(s, old, new string) string {
	for i := 0; i+len(old) <= len(s); i++ {
		if s[i:i+len(old)] == old {
			return s[:i] + new + s[i+len(old):]
		}
	}
	return s
}

func (m *Module) collect(ctx context.Context, now time.Time, modes fairuse.Modes, ex exclusionState) ([]Detection, error) {
	var out []Detection
	var errs []error
	on := func(k Kind) bool { return modes.Of(string(k)) != fairuse.ModeOff }

	if on(KindVolume) || on(KindResell) || on(KindBT) || on(KindMail) || on(KindScan) {
		dets, err := m.collectCounters(ctx, now, ex)
		if err != nil {
			errs = append(errs, fmt.Errorf("counters: %w", err))
		}
		for _, d := range dets {
			if on(d.Kind) {
				out = append(out, d)
			}
		}
	}
	if on(KindSharing) {
		dets, err := m.collectSharing(ctx, now, ex)
		if err != nil {
			errs = append(errs, fmt.Errorf("sharing: %w", err))
		}
		out = append(out, dets...)
	}
	if on(KindLeak) {
		dets, err := m.collectLeak(ctx, now, out, ex)
		if err != nil {
			errs = append(errs, fmt.Errorf("leak: %w", err))
		}
		out = append(out, dets...)
	}
	return out, errors.Join(errs...)
}
