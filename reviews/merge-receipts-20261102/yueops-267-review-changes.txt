## Cross-repo coupling that isn't visible in any single repo

- **Subscription generation is a contract between yueboard and every client family.** `yueboard/internal/modules/subscribe/` renders Clash Meta, Surge, Loon, Quantumult X, Surfboard, sing-box, and general links from native templates. There is no `?yl=1` or device-specific server branch. When one client fails, render its exact User-Agent and compare fields against a working renderer before changing the fleet.
- **The server template is the YueLink source of truth.** YueLink no longer inlines `GeoIP.dat`/`GeoSite.dat`; it seeds the exact bundled `.mrs` set and preserves server routing. Keep client transforms bounded to compatibility defaults, and use the reference clients to justify any divergence.
- **The schema is native; remaining cross-service reads are explicit migration debt.** Tables use native names, `numeric` amounts, `jsonb`, and `timestamptz`. YueBoard owns panel-domain writes. Any temporary YueOps read must be catalogued and moved behind a scoped native internal API before its DB credential is removed.
- **Panel↔node control is ConnectRPC only.** The protobuf contract is shared by yueboard and yue-node. Every physical host must use a machine-scoped credential and exact assignment; a fleet-wide token, REST polling, or WS push is a migration regression.
- **🚨 Never rebuild a node by copying another node's `/home/yue-node` wholesale.** The runtime tree
  contains `node-*/data/report-outbox`, which is the machine's **billing identity**. Cloning it either
  double-bills or wedges the node forever on `report sequence gap`, which has no recovery path. This
  has now happened twice (2026-08-01, 2026-08-11). **Wipe `node-*/data/report-outbox` before first
  start** — the in-code owner guard only protects hosts already running yue-node `4bf9ada` or newer.
  📎 Full provisioning / cloning / retiring / hard-delete procedure: the **`node-lifecycle`** skill.

## Release / CI: what is true in every session

Four things must name the same commit: the reviewed **pin**, the source repo **HEAD**, the
**promoted** image, and what **production** actually runs. `release-state.py` prints all four.
- **2026-10-12: SSH authority is ACTIVE.** Every new yueops revision needs auto-pull + `make-release-root.sh
  --strict` + `scripts/ship-sshd-authority.py --apply` before Ops/panel deploys or A/B publishing (ship.sh chains them).
- **2026-10-11: bastion is CPU-steal-bound** (60–78%): no heavy tests there; check `vmstat` st first. 📎 `release-chain`.

**Before pushing `yueboard/master`, establish its effect on the active release.**
Promotion requires default-branch ancestry, inputs identical to HEAD and a candidate
not older than `:latest`. A changed input can invalidate a running release.
When inputs change, the integration owner must complete these steps:

1. Read the revision labels off the **running production** panel image and node fleet, then run
   `scripts/converge-yueboard-release-pin.py --from-head --deployed-board-revision <prod-board>
   --deployed-node-revision <prod-node>`. Both are explicit because reviewed candidates may never
   have been deployed. It updates yueto-ci's two copies atomically and **derives** the schema
   floor from `git show <rev>:schema-floor.txt`; since P2 §4 A3 it no longer writes yueops.
2. Coordinate the required rebuild and panel deployment with the release owner.
   The desired state yueops deploys from is the **signed** root `release.yaml`
   (ship.sh writes + seals it; no pin is committed back into yueops). 📎 `release-chain`.

Promote, `release-state.py` and the schema-migrator contract accept a descendant
with unchanged native image inputs and the same schema floor while retaining the
reviewed pin. Use the actual input comparator: a Markdown or test filename alone
does not establish equivalence. Changed or unknown inputs retain the normal pin
convergence and release requirements. Preserve each active writer's source custody.

job annotation decisive) before reading any red run; the local `gauntlet.sh` is the real gate either way.

YueOps has five components: Python CLI, FastAPI web service, modular React frontend, Telegram Bot (yue), and YueLink Checkin API. User interfaces support Simplified Chinese and English. Python ≥3.10; React 19 + TypeScript (rewritten from Vue 3 in v4.0). The active protocols are **HY2 + Reality**; AnyTLS, ShadowTLS and SS2022 are retired.

**Do not use this document as the fleet count.** Direct hosts, serving assignments and unique enabled nodes come from `scripts/node-control-auth-migrate.py --baseline-check`, production inventory and the applicable canonical rollout evidence. Documents are projections that expire; a stale handwritten count can make a guard assert a false production fact and still pass. Historical explicit baseline reviews, including dates, SIDs and reasons for changes to all three counts, are preserved in the `yueops-agent-deploy` skill's fleet review history.

Both containers were gone, compose had not started, the maintenance lease remained open and :443 was unavailable. `require_local_hy2_certificate_material` now checks readability in the host-read-only phase; the other three inputs remain mandatory.

**Restart PG primary only with `systemctl restart postgresql@18-main`, never `pg_ctl restart`.** On 2026-08-03 at 19:41, `pg_ctl restart -m fast -w` was held by an SSH session that a simultaneous bastion restart terminated. Shutdown completed (11:41:37, "database system is shut down"), but startup never executed; the `sudo` session closed at 11:41:35. PG stayed down until a manual start at 20:56. The panel crash-looped for 75 minutes (`yueboard` restartCount 41→61), with no alerts.

The old claim that a failed systemctl/pg_ctlcluster redirect leaves PG running **does not apply to this host**: `postgresql@.service` ExecStart uses `--skip-systemctl-redirect`. A recorded `systemctl restart postgresql@18-main` completed in nine seconds (14:14:28→14:14:37) with a new postmaster PID.

Companion safeguards installed on `.237`:

- `postgresql@18-main.service.d/override.conf`: `Restart=always`, `RestartSec=10`. **Do not use `Restart=on-failure`**: fast shutdown exits 0, so that setting misses this failure. A recorded external `pg_ctl -m fast stop` recovered automatically in 12 seconds, PID 637053→644886.
- `pg-watchdog.timer` (60s) covers a stuck start: the unit has `TimeoutStartSec=infinity`, so it can remain activating forever without triggering `Restart=`. Use `pg_isready` exit codes: `2` means no response and allows intervention; `1` means rejecting connections, potentially crash recovery, which must not be interrupted.
- Planned shutdown uses `systemctl stop postgresql@18-main` or `touch /etc/postgresql-maintenance.lock`; the watchdog yields to the lock.

### Two-stage rollout for check-in traffic settlement

The panel_ledger ACK consumer reads the original byte-allocation plan in reward-anchor `metadata.traffic_settlement_v1`. It validates subject, reference, idempotency key and actual receipt range, then updates every row and marks the outbox done in one transaction. Invalid plans must not fall back to single-row allocation. The plan is server-only, excluded from Board wire and user responses; existing single-row semantics for other producers stay unchanged.

Release consumer-only first, keeping the old check-in producer. Read back the images for checkin-api's resident worker and yue-bot's watch consumer, including exit of the old processes, before releasing the producer. Native service order is web → checkin → bot; **do not skip the intermediate consumer-only release**. Producer rollback must target consumer-only. While new-format work is unfinished, do not downgrade to an old consumer that cannot process it.

The producer creates all reward rows in one transaction, then links `outbox.reward_ledger_id` to the first traffic row. Plan-request bytes and Board payload use the same integer. Four-decimal GB amounts use differences between cumulative actual values; `metadata.applied_bytes` retains exact bytes.

### Auth API

- **Two-factor login is mandatory (2026-09-26).** Primary entry: YueBoard admin's YueOps console item → `/sso/board` → `POST /auth/board-sso`; Board TOTP/passkey supplies the second factor. Public `POST /auth/login` password validation is only the first factor and returns `{second_factor_required:true, second_factor:"board_sso"}`, **without issuing a session**. Accounts without `board_user_id` return403 `second_factor_unavailable`. Bastion loopback with no `CF-Connecting-IP` is the password-only emergency entry, returning `{access_token, must_change_password}`. `POST /auth/change-password` accepts `{old_password,new_password}` (≥8 characters).
- WS `/api/tasks/{id}/ws` accepts the token only in `Sec-WebSocket-Protocol`, never the query string.
- Trust X-Forwarded-For only when `request.client.host` is127.0.0.1 or`::1`.

# Guard authoring (Yue.to)

The expensive failure is a green guard protecting nothing. The linked incident examples
occurred in actual production work.

Apply the checklist to the guard's actual inputs, dependencies and claimed
coverage. Running an existing check does not require redesigning it. A changed
assertion, scan boundary or success/failure classification does require this skill.
For import/fixture leakage, load [test isolation](references/test-isolation.md)
first; use the guard checklist only if guard coverage changes.

Before adding an invariant, establish which consumer needs it and check its
actual semantics. Challenge it with one realistic counterexample at that boundary:
subprocess execution for locks, a write failure for persistence, or raw single-target
output for collectors. Matching strings or unrelated runner-image labels cannot
establish those properties. Reuse the recorded interpreter/image, user and mounts;
classify failures as startup, collection or assertion before editing product code.

## Establish three facts before accepting green

1. Did this run reach the target? Zero executions is not a pass.
2. Did the scan cover the intended objects? Zero matches is not universal success.
3. Is the guarded layer the layer users and production actually encounter?

A negative answer makes the green result meaningless.

only when its failure class applies; the catalog is retained evidence, not an
extra audit assignment.

## Required guard-delivery checklist

- [ ] Remove/rename/delete the protected object in an isolated mutation: the
  guard must fail, not mistake missing input for correctness.
- [ ] Exercise dependency failures the guard can encounter: wrong credentials
  for authenticated probes, network failure for remote probes, and permission
  failure for protected inputs. Verify their visible classifications.
- [ ] For scans, require a minimum target count; for a single target, prove arrival.
- [ ] Before counting negative observations, prove target-handler arrival and
  run controls protecting legitimate behavior.
- [ ] Register cross-repository guards in `scripts/check-all-contracts.sh`.
  `<path>` must name the sibling file actually read, not the guard script itself;
  otherwise missing-repository SKIP is unreachable. `guard-ci-claims` enforces it.
- [ ] Enumerate every criterion dimension, such as status × amount × ownership.
- [ ] Never duplicate live fleet counts. Since 2026-09-14, derive them from
  `servers.deploy_mode='direct'`; node-control-auth-migrate.py EXPECTED baselines
  no longer exist. Documentation may retain dated snapshots. Only mechanically
  enforced authoritative projections and date-anchored observations are exceptions.

## Workspace-only guards

`scripts/check-all-contracts.sh` alone knows the complete cross-repository guard
set. Single-repo CI cannot see all private siblings; a green component does not
establish a shared contract. The registry explicitly states whether a component
CI consumer exists.

A 2026-08-02 isolated Ops checkout showed whole tests skipped in ci-backend.yml:
`panel-deep-links` (2), `idempotency-catalog` (5, module-level pytestmark),
`registry-links` (2), and cross-surface design-token-gate cases. These and the
root scripts-level comparators run only in the workspace. Run the contract script
before pushing cross-repository changes.

`guard-ci-claims` (`scripts/check-guard-ci-claims.py`) fails when sibling-dependent
entries lack workspace-only marking or claimed component CI lacks a workflow
execution path. Missing repositories must report SKIP; `<path>` identifies the
actual sibling input, never the guard itself, so missing input cannot appear PASS.

`scripts/gauntlet.sh` similarly turns a former verbal pre-release promise into
execution: missing tools/repos are SKIP, never PASS, and too few actually executed
stages fail the gate.

### YueBoard Panel / shared DB

- **Panel DB 在 PG primary `.237:5432`**；YueBoard 是 Go 单二进制，容器内监听 `:8080`，由 nginx 公开 443。候选生产容器只接入 `nginx_default`；数据库走已验证的直连 DSN，禁止为 Redis/旧面板重新接入 `yue-to_default`。
- **YueBoard 部署只用仓库托管的 `scripts/deploy-yueboard-panel.sh <immutable-manifest-digest>`**。脚本验签、拒绝 tag/旧环境变量、要求单网络和只读/零 capability 容器，验 ready 后才完成切换，失败自动回滚。禁止再运行 `/home/xboard/yue-to`、`web/ws/horizon`、Laravel Octane 或 XBoard Redis 指令。
- **Panel 直连 PG 5432，不经 PgBouncer transaction pool**；这是当前 Go/pgx 的已验证生产路径。旧 PHP-PDO/Octane 25P02 事故仅保留为历史背景。
- **XBoard fork、Portal 和 runtime patches 已退出请求链**。panel 上暂存的旧 Redis、`/home/xboard` 与遗留镜像只用于候选发布前回滚，仍属待删除卫生债，绝不能误称已物理退役；新 digest 观察窗通过后按原生退役门统一删除。
- **订阅模板 geo 规则全走自建镜像 `geo.yuetong.app`**（R2 `yue-geo`，bastion `sync-geo-rules-r2.sh`+每 6 小时 timer，清单从模板自动推导）：clashmeta=39 `.mrs` 二进制（mihomo ≥1.18.7，无 geodata 整包/无 GEOIP/GEOSITE；openai/claude 高频已转内联）；stash/clash=bm7 classical yaml 镜像；surge/surfboard=bm7 Surge list 镜像；singbox=`.srs`。**镜像域必须 DIRECT 规则**（rule-provider 下载走客户端自身路由，落 MATCH→代理则节点全断时规则拉不下来）。**禁止 `type: smart` 组**（vernesong 分支私货，官方 mihomo 报错）。**CF cache rule**（zone yuetong.app, host=geo.yuetong.app, respect_origin）让边缘缓存 → 与单点 R2 源解耦；上传 `Cache-Control max-age=3600`(1h)，全量校验与 R2 回读后才更新 manifest；失败保留旧版，回滚用 R2 `snapshots/`，完整安装入口 `install-geo-rules-sync.sh`。R2 自定义域默认 `cf-cache-status: DYNAMIC` 不缓存，必须显式建 cache rule。
- **订阅模板事实源是 `subscribe_templates` + YueBoard 管理端保存接口**；YueBoard 渲染器直接读取原生表，不存在 Laravel `SubscribeTemplate::flushCache()`/Octane 重启步骤。**sniffer.override-destination 必 false**（2026-09-03 改判，全局/TLS/QUIC 三处 false、仅 HTTP 段 true，与 mihomo `docs/config.yaml` 示例同形）：`component/sniffer/dispatcher.go` `replaceDomain()` 里嗅探到的 SNI **无论如何**都会写进 `metadata.SniffHost`，而 `Metadata.RuleHost()` 优先取它，所以**规则匹配不受影响**；`override-destination` 只决定要不要把 `metadata.Host` 换成域名并**清掉 `DstIP`** —— 清掉之后 mihomo 自己重新解析，HTTPDNS/直连 IP 型国内 App（美团 Shark、淘宝、微信）会被解到另一个 CDN 边缘（实测 `api.smoot.apple.cn` → 东京 AWS），这是「国内 App 很慢」的另一半。旧的「必 true」理由是「客户端发 IP 不发域名 → 审计失效」，但**代码里没有这个审计**：`service/fair_use_audit.py` / `dao/fair_use.py` 全按流量口径统计、零处读目的域名，yue-node 也刻意关掉了内容嗅探。守卫 `tests/test_subscription_quic_fallback_20260805.py`（模板值 + 本句与 RUNBOOK 的反向文档门）。；**手机端 UA** `SFA/版本`/`SFI/版本`（不是 `sing-box`）；**国家码**边界匹配。

# Prove that a guard detects a real failure

Before delivery, establish all three properties:

1. **It fails when the protected fact is broken.** Run a mutation test; without
   this, the guard is not delivered.
2. **It checks the actual consumer.** Importability does not establish execution.
   Removing `if __name__ == "__main__"` can leave importlib-based tests green
   while the actual script silently exits without doing work.
3. **It has a legitimate path to success.** A permanently failing guard with no
   valid remediation is ineffective. Silent `return 1`, single instantaneous
   samples and text-only assertions require particular care.

A missing repository is SKIP, never PASS. Each registered `<path>` must identify
the sibling file actually consumed by the guard. Use `~/.venvs/yueto/bin/python`
for pytest; explicitly select `scripts/test-*.py` because their hyphenated names
are not discovered by pytest's default patterns.

Read `guard-authoring` for the incident patterns and mandatory checklist, and
`change-blast-radius` before removing checks or changing boundaries.

def read(path):

def uncomment(sql):
    return re.sub(r"--[^\n]*|/\*.*?\*/", " ", sql, flags=re.S)


# Only concrete table/column GRANTs: never treat template %I, ALL TABLES,
# default privileges, or a verification query as an executable grant.
GRANT = re.compile(
    r"\bGRANT\s+([^;']+?)\s+ON\s+(?:TABLE\s+)?"
    r"((?:public\.)?[a-z_][a-z_0-9]*(?:\s*,\s*(?:public\.)?[a-z_][a-z_0-9]*)*)\s+TO\s+"
    r"([a-z_][a-z_0-9]*(?:\s*,\s*[a-z_][a-z_0-9]*)*)\s*;", re.I)



def parse_grants(sql):
    acl = defaultdict(set)
    for match in GRANT.finditer(uncomment(sql)):
        privileges, tables, roles = match.groups()
        for op, columns in re.findall(r"(SELECT|INSERT|UPDATE|DELETE|ALL(?:\s+PRIVILEGES)?)\s*(?:\(([^)]*)\))?", privileges, re.I):
            for role in roles.replace(" ", "").replace("\n", "").split(","):
                for table in tables.split(","):
                    for privilege in ("SELECT", "INSERT", "UPDATE", "DELETE") if op.upper().startswith("ALL") else (op.upper(),):
                        acl[role, table.strip().removeprefix("public."), privilege].update(
                            c.strip().strip('"') for c in columns.split(",") if c.strip()
                        ) if columns else acl[role, table.strip().removeprefix("public."), privilege].add("*")
    return acl

def fold(node, constants):
    if isinstance(node, ast.Constant) and isinstance(node.value, str):
        return node.value
    if isinstance(node, ast.Name):
        return constants.get(node.id, "{dynamic}")
    if isinstance(node, ast.JoinedStr):
        return "".join(fold(v.value, constants) if isinstance(v, ast.FormattedValue) else fold(v, constants) for v in node.values)
    if isinstance(node, ast.BinOp) and isinstance(node.op, ast.Add):
        return fold(node.left, constants) + fold(node.right, constants)
    return "{dynamic}"

IDENT = r'[a-z_][a-z_0-9]*'


# Names that exist only as CTEs in fleet SQL (no relation of that name is
# created in any SQL file). Only these are ever dropped, and only from SQL that
# declares them as a CTE, so every real-table requirement is kept.
CTE_ONLY_RELATIONS = frozenset({"eligible_servers"})


def requirements(sql):
    """Column requirements on real relations; known CTE-only names are not tables."""
    declared = {name.lower() for name in re.findall(
        r"(?:\bWITH(?:\s+RECURSIVE)?|,)\s*(" + IDENT + r")\s+AS\s+(?:NOT\s+)?(?:MATERIALIZED\s+)?\(",
        uncomment(sql), re.I)} & CTE_ONLY_RELATIONS
    for table, op, col in _requirements(sql):
        if table.lower() not in declared:
            yield table, op, col


def test_cte_only_relations_are_not_real_relations():
    pattern = re.compile(r"\b(?:CREATE|ALTER)\s+(?:TABLE|VIEW|MATERIALIZED\s+VIEW)\s+(?:IF\s+NOT\s+EXISTS\s+)?(?:public\.)?(" + IDENT + r")\b", re.I)
    defined = set()
    for path in ROOT.rglob("*.sql"):
        defined |= {m.lower() for m in pattern.findall(path.read_text(errors="replace"))}
    assert defined and not (CTE_ONLY_RELATIONS & defined)


def test_requirements_drop_only_known_cte_names():
    assert set(requirements(
        "WITH eligible_servers AS MATERIALIZED (SELECT sid FROM servers) SELECT sid FROM eligible_servers"
    )) == {("servers", "SELECT", "sid")}
    assert ("users", "SELECT", "last_login_ip") in set(requirements(
        "WITH users AS (SELECT last_login_ip FROM users) SELECT last_login_ip FROM users"))
    assert ("users", "SELECT", "last_login_ip") in set(requirements(
        "SELECT '$$' AS note, last_login_ip FROM users WHERE email = '$$'"))
    assert ("eligible_servers", "SELECT", "sid") in set(requirements("SELECT sid FROM eligible_servers"))


def _requirements(sql):
    """Extract only unambiguous explicit projection/target column lists.

    General expressions and predicates remain gaps, not guessed identifiers.
    Qualified references require a unique explicit AS alias in the SQL string.
    """
    sql = uncomment(sql)
    # A CTE is a query result, not a separately granted table. Its defining
    # SELECT is scanned below, so source-table requirements remain enforced.
    scrubbed = re.sub(r"'(?:[^']|'')*'", "''", sql)
    cte_ends = {}
    for cte in re.finditer(
        r'(?:\bWITH\s+|,\s*)(' + IDENT
        + r')\s*(?:\([^)]*\))?\s+AS\s+(?:NOT\s+)?(?:MATERIALIZED\s+)?\(',
        scrubbed, re.I,
    ):
        depth = 1
        for end in range(cte.end(), len(scrubbed)):
            depth += (scrubbed[end] == "(") - (scrubbed[end] == ")")
            if depth == 0:
                cte_ends[cte[1].lower()] = end
                break
    # Keep offsets aligned after removing literal contents.
    sql = scrubbed
    def derived_reference(table, schema, offset):
        end = cte_ends.get(table.lower(), len(sql))
        return not schema and sql.rfind(";", 0, offset) < end < offset

    for m in re.finditer(r"\bSELECT\s+((?:(?!\bSELECT\b).)*?)\s+FROM\s+(public\.)?(" + IDENT + r")\b", sql, re.I | re.S):
        projection, schema, table = m.groups()
        if derived_reference(table, schema, m.start()) or re.search(r"\bSELECT\b", projection, re.I):
            continue
        alias_match = re.match(r"\s+(?:AS\s+)?(" + IDENT + r")\b", sql[m.end():], re.I)
        alias = alias_match[1] if alias_match else table
        for item in projection.split(","):
            item = re.sub(r"^\s*" + re.escape(alias) + r"\.", "", item)
            col = re.fullmatch(r'\s*(?:DISTINCT\s+)?("?' + IDENT + r'"?)\s*(?:AS\s+' + IDENT + r')?\s*', item, re.I)
            if col and col[1].upper() not in {"NULL", "TRUE", "FALSE", "NOT"}:
                yield table, "SELECT", col[1].strip('"')
    # Single-table predicates have unambiguous attribution. Other SQL shapes
    # remain listed gaps; literals and bound parameter names are not columns.
    refs = re.findall(r"\bFROM\s+(?:public\.)?(" + IDENT + r")\b", sql, re.I)
    if len(refs) == 1 and not re.search(r"\b(JOIN|WITH|UNION|INSERT|UPDATE|DELETE)\b", sql, re.I):
        tail = re.split(r"\bWHERE\b", sql, maxsplit=1, flags=re.I)
        if len(tail) == 2:
            predicates = re.sub(r"\b[a-z_]+\s*=>", " ", tail[1], flags=re.I)
            predicates = re.sub(r"'(?:[^']|'')*'|%\([^)]+\)s|%s|:[a-z_]+", " ", predicates, flags=re.I)
            for col in re.findall(r"(?<![.:])\b(" + IDENT + r")\s*(?==|<>|>=|<=|>|<|\bIS\b|\bIN\b|\bLIKE\b)", predicates, re.I):
                if col.upper() not in {"NULL", "TRUE", "FALSE", "NOT"}:
                    yield refs[0], "SELECT", col
    # Qualified references in projections/predicates/joins are attributable
    # when the alias maps to exactly one relation throughout this SQL string.
    aliases = defaultdict(set)
    for ref in re.finditer(r"\b(?:FROM|JOIN)\s+(public\.)?(" + IDENT + r")\s+AS\s+(" + IDENT + r")", sql, re.I):
        schema, table, alias = ref.groups()
        if not derived_reference(table, schema, ref.start()):
            aliases[alias].add(table)
    scrubbed = re.sub(r"'(?:[^']|'')*'", " ", sql)
    for alias, col in re.findall(r"\b(" + IDENT + r")\.(" + IDENT + r")\b", scrubbed):
        if len(aliases[alias]) == 1:
            yield next(iter(aliases[alias])), "SELECT", col
    for m in re.finditer(r"\bINSERT\s+INTO\s+(?:public\.)?(" + IDENT + r")\s*\(([^)]+)\)", sql, re.I):
        for col in m[2].split(","):
            if re.fullmatch(IDENT, col.strip()):
                yield m[1], "INSERT", col.strip()
    for m in re.finditer(r"\bUPDATE\s+(?:public\.)?(" + IDENT + r")\s+SET\s+(.*?)(?:\bWHERE\b|\bRETURNING\b|;|$)", sql, re.I | re.S):
        for col in re.findall(r"(?:^|,)\s*(" + IDENT + r")\s*=", m[2]):
            yield m[1], "UPDATE", col

    for table in re.findall(r"\bDELETE\s+FROM\s+(?:public\.)?(" + IDENT + r")\b", sql, re.I):
        yield table, "DELETE", "*"


@lru_cache(None)
def inventory(service):
    acl = policy(service)
    checked, unknown = set(), set()
    tables = {table for table, _ in acl}
    for site, sql in sources(service):
        for table, op, column in requirements(sql):
            # Multi-DSN operational scripts and web: only the tables in this
            # connection's policy can be assigned without dataflow analysis.
            if service.role not in {"app_checkin", "app_yue_bot"} and table not in tables:
                unknown.add((site, table, op, column))
                continue
            if "auditor" in service.role and op != "SELECT":
                continue
            if service.role == "app_yueops_web_bot_ro" and op != "SELECT":
                continue
            allowed = acl.get((table, op))
            closed = bool(service.policy) or table == "users" or (
                service.role == "app_yue_bot" and table == "orders"
            ) or allowed == set()
            covered = allowed is not None and (closed or "*" in allowed or column in allowed)
            target = checked if covered else unknown
            target.add((site, table, op, column))
    return checked, unknown


def missing(service):
    acl = policy(service)
    return sorted(item for item in inventory(service)[0]
                  if "*" not in acl[item[1], item[2]] and item[3] not in acl[item[1], item[2]])

@pytest.mark.parametrize("readonly,allowed", [(False, True), (True, False), (True, True)])
def test_live_probe_reaches_privilege_check_and_rejects_denial(readonly, allowed):
    class Cursor:
        def __init__(self):
            self.calls = []
            self.answer = None

        def __enter__(self):
            return self

        def __exit__(self, *args):
            pass

        def execute(self, query, args=None):
            self.calls.append(query)
            if query.startswith("SHOW"):
                self.answer = "on" if readonly else "off"
            elif "has_table_privilege" in query:
                self.answer = allowed if args[-1] == "DELETE" else False
            elif "has_column_privilege" in query:
                self.answer = allowed
            else:
                self.answer = True

        def fetchone(self):
            return (self.answer,)

    class Connection:
        def __init__(self):
            self.cur = Cursor()

        def cursor(self):
            return self.cur

    connection = Connection()
    if readonly and allowed:
        live_check(connection, SERVICES[0])
        assert any("has_column_privilege" in q for q in connection.cur.calls)
        assert any("has_table_privilege" in q for q in connection.cur.calls)
    else:
        with pytest.raises(AssertionError):
            live_check(connection, SERVICES[0])

def _dynamic_sql_user(table: str) -> bool:

    if not path.is_file():

def _migration_sql(text: str) -> str:
    """Mask comments and string/dollar literals before reading static DDL.

    Procedural bodies are opaque: never infer a DROP from a function definition
    or dynamic SQL. This inventory does not execute conditional migrations.
    """
    tokens = re.compile(r"--[^\n]*|/\*|[Ee]'(?:\\.|''|[^'\\])*'|'(?:[^']|'')*'|\$(?:[a-z_][a-z0-9_]*)?\$", re.I)
    result, start = [], 0
    while match := tokens.search(text, start):
        result.append(text[start:match.start()])
        token = match.group()
        end = match.end()
        if token == "/*":
            depth = 1
            while depth:
                marker = re.search(r"/\*|\*/", text[end:])
                if marker is None:
                    raise ValueError("unterminated migration comment")
                depth += 1 if marker.group() == "/*" else -1
                end += marker.end()
        elif token.startswith("$"):
            close = text.find(token, end)
            if close < 0:
                raise ValueError("unterminated migration dollar literal")
            end = close + len(token)
        result.append(" ")
        start = end
    result.append(text[start:])
    return "".join(result)


def created_tables() -> dict[str, str]:
    """Surviving table name -> creation migration, after ordered DROP statements.

    This is the repository migration lifecycle, not proof of applied production
    state. SQL comments and string literals must not execute rollback examples.
    """
    out: dict[str, str] = {}
    statements = re.compile(
        r"(?P<create>CREATE TABLE(?:\s+IF NOT EXISTS)?\s+(?P<created>[a-z_][a-z0-9_]*))"
        r'|(?P<drop>DROP TABLE(?:\s+IF EXISTS)?\s+(?:public\.)?"?(?P<dropped>[a-z_][a-z0-9_]*)"?)',
        re.I | re.S,
    )
    for path in sorted(MIGRATIONS.glob("*.sql")):
        text = path.read_text(encoding="utf-8", errors="ignore")
        for match in statements.finditer(_migration_sql(text)):
            if match.group("create"):
                out.setdefault(match.group("created").lower(), path.name)
            elif match.group("drop"):
                out.pop(match.group("dropped").lower(), None)
    return out

            if path.is_relative_to(MIGRATIONS):
                continue
            files.append((path, path.read_text(encoding="utf-8", errors="ignore")))
    return files

Promotion requires default-branch ancestry, inputs identical to HEAD and a candidate

1. Read the revision labels off the **running production** panel image and node fleet, then run

   --deployed-node-revision <prod-node>`. Both are explicit because reviewed candidates may never
   have been deployed. It updates yueto-ci's two copies atomically and **derives** the schema
   floor from `git show <rev>:schema-floor.txt`; since P2 §4 A3 it no longer writes yueops.
2. Coordinate the required rebuild and panel deployment with the release owner.
   The desired state yueops deploys from is the **signed** root `release.yaml`

Promote, `release-state.py` and the schema-migrator contract accept a descendant
with unchanged native image inputs and the same schema floor while retaining the
reviewed pin. Use the actual input comparator: a Markdown or test filename alone
does not establish equivalence. Changed or unknown inputs retain the normal pin
convergence and release requirements. Preserve each active writer's source custody.
