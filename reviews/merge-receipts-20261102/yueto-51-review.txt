- **Subscription generation is a contract between yueboard and every client family.** `yueboard/internal/modules/subscribe/` renders Clash Meta, Surge, Loon, Quantumult X, Surfboard, sing-box, and general links from native templates. - **Panel↔node control is ConnectRPC only.** The protobuf contract is shared by yueboard and yue-node. Every physical host must use a machine-scoped credential and exact assignment; a fleet-wide token, REST polling, or WS push is a migration regression.

# Guard authoring (Yue.to)

The expensive failure is a green guard protecting nothing. The linked incident examples
occurred in actual production work.

Apply the checklist to the guard's actual inputs, dependencies and claimed
coverage. Running an existing check does not require redesigning it. A changed
assertion, scan boundary or success/failure classification does require this skill.
For import/fixture leakage, load [test isolation](references/test-isolation.md)
first; use the guard checklist only if guard coverage changes.

Before adding an invariant, establish which consumer needs it and check its
actual semantics. Challenge it with one realistic counterexample at that boundary:
subprocess execution for locks, a write failure for persistence, or raw single-target
output for collectors. Matching strings or unrelated runner-image labels cannot
establish those properties. Reuse the recorded interpreter/image, user and mounts;
classify failures as startup, collection or assertion before editing product code.

## Establish three facts before accepting green

1. Did this run reach the target? Zero executions is not a pass.
2. Did the scan cover the intended objects? Zero matches is not universal success.
3. Is the guarded layer the layer users and production actually encounter?

A negative answer makes the green result meaningless.

## Load only the relevant incident reference

Keep the common criteria and checklist below for guard changes. Read a reference
only when its failure class applies; the catalog is retained evidence, not an
extra audit assignment.

- [ ] Exercise dependency failures the guard can encounter: wrong credentials

# Prove that a guard detects a real failure

Before delivery, establish all three properties:

1. **It fails when the protected fact is broken.** Run a mutation test; without
   this, the guard is not delivered.
2. **It checks the actual consumer.** Importability does not establish execution.
   Removing `if __name__ == "__main__"` can leave importlib-based tests green
   while the actual script silently exits without doing work.
3. **It has a legitimate path to success.** A permanently failing guard with no
   valid remediation is ineffective. Silent `return 1`, single instantaneous
   samples and text-only assertions require particular care.

A missing repository is SKIP, never PASS. Each registered `<path>` must identify
the sibling file actually consumed by the guard. Use `~/.venvs/yueto/bin/python`
for pytest; explicitly select `scripts/test-*.py` because their hyphenated names
are not discovered by pytest's default patterns.

Read `guard-authoring` for the incident patterns and mandatory checklist, and
`change-blast-radius` before removing checks or changing boundaries.

def clean_git_env(env=None):
    return {key: value for key, value in (os.environ if env is None else env).items()

def check_checkout_health(root):
    """Read explicit checkout config; never repair a checkout behind its owner."""
    if not root.is_dir():
        raise ValueError(f'checkout-health: workspace missing: {root}')
    checkouts = [path for path in [root, *sorted(root.iterdir())]
                 if (path / '.git').exists()]
    if not checkouts:
        raise ValueError(f'checkout-health: no checkouts found: {root}')
    for checkout in checkouts:
        try:
            bare = git(checkout, 'config', '--local', '--bool', 'core.bare')
        except subprocess.SubprocessError as error:
            raise ValueError(f'checkout-health: cannot read core.bare: {checkout}') from error
        if bare != 'false':
            raise ValueError(f'checkout-health: core.bare={bare}: {checkout}; '
                             'stop and investigate repository environment leakage')
    print(f'checkout-health: PASS ({len(checkouts)} checkouts in {root})', flush=True)


def git(repo, *args):
    return subprocess.check_output(['git', '-C', str(repo), *args], text=True,
                                   stderr=subprocess.DEVNULL, env=clean_git_env()).strip()


def workers():
    """Reserve headroom; cap both host and cgroup memory, CPU and user limits."""
    limits = []
    try:
        for line in Path('/proc/meminfo').read_text().splitlines():
            if line.startswith('MemAvailable:'):
                limits.append(int(line.split()[1]) * 1024)
        maximum = Path('/sys/fs/cgroup/memory.max').read_text().strip()
        if maximum != 'max':
            limits.append(max(0, int(maximum) - int(Path('/sys/fs/cgroup/memory.current').read_text())))
    except (OSError, ValueError):
        pass
    memory = min(limits) if limits else 2 * 1024**3
    return max(1, min(6, os.cpu_count() or 1, int(os.environ.get('YT_PAR', '6')),
                      max(1, (memory - 512 * 1024**2) // (1536 * 1024**2))))


def ops_summary(directory):
    admission = json.loads((directory / 'rt/adm.json').read_text())

def link_tag(source):
    matches = re.findall(r'^version:\s+(\d+\.\d+\.\d+)(?:\+\d+)?\s*$',
                         (source / 'pubspec.yaml').read_text(), re.M)
    if len(matches) != 1:
        raise ValueError('missing or ambiguous stable client version')
    return 'v' + matches[0]


def check_link_tag(source, sha):
    tag = link_tag(source)
    if git(source, 'tag', '--list', tag):
        if git(source, 'rev-parse', f'refs/tags/{tag}^{{commit}}') != sha:
            raise ValueError('client version already tagged at another revision')


class Runner:
    timeout = 7200

    def __init__(self, cwd, logs, env):
        self.cwd, self.logs, self.env = cwd, logs, clean_git_env(env)
        self.results = []

    def run(self, name, command, stdin=None):
        path = self.logs / (name + '.log')
        try:
            with path.open('w') as out:
                with subprocess.Popen(command, cwd=self.cwd, env=self.env,
                                      stdin=subprocess.PIPE, text=True, stdout=out,
                                      stderr=subprocess.STDOUT, start_new_session=True) as child:
                    try:
                        child.communicate(input=stdin, timeout=self.timeout)
                        rc = child.returncode
                    finally:
                        # Kill only this gate's owned process group before its
                        # temporary checkout can be removed, including workers.
                        try:
                            os.killpg(child.pid, signal.SIGKILL)
                        except ProcessLookupError:
                            pass
        except subprocess.TimeoutExpired:
            rc = 124
        except OSError:
            rc = 127
        self.results.append((name, rc))
        print(f'{name}: {"PASS" if rc == 0 else "FAIL"} (log: {path})', flush=True)
        return rc

    def failure(self, name):
        self.results.append((name, 1))

def link_core(repo, source, sha, created):
    """Use the initialized core's objects without changing its checkout or index."""
    path = 'core/mihomo'
    entry = git(source, 'ls-tree', sha, '--', path).split()
    if len(entry) != 4 or entry[0:2] != ['160000', 'commit'] or entry[3] != path:
        raise ValueError('missing required mihomo gitlink')
    owner = repo / path
    # Git would otherwise walk up to the parent when the submodule is absent.
    if Path(git(owner, 'rev-parse', '--show-toplevel')).resolve() != owner.resolve():
        raise ValueError('mihomo object repository is not initialized')
    checkout = source / path
    subprocess.run(['git', '-C', str(owner), 'worktree', 'add', '--detach', '--quiet',
                    str(checkout), entry[2]], check=True, env=clean_git_env(),
                   stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    created.append((owner, checkout))

import ast

ROOT = Path(__file__).resolve().parents[1]
# 与 check-all-contracts 里最慢的脚本式守卫同量级留余量；超时算失败，不算通过。
SCRIPT_GUARD_TIMEOUT_S = 900


def _has_collectable_tests(tree: ast.Module) -> bool:
    for node in tree.body:
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)) and node.name.startswith("test"):
            return True
        if isinstance(node, ast.ClassDef):
            if node.name.startswith("Test"):
                return True
            for base in node.bases:
                name = base.attr if isinstance(base, ast.Attribute) else getattr(base, "id", "")
                if name == "TestCase":
                    return True
        # `test_x = some_factory(...)` 这类赋值出来的测试也算可收集。
        if isinstance(node, ast.Assign):
            for target in node.targets:
                if isinstance(target, ast.Name) and target.id.startswith("test"):
                    return True
    return False


def is_script_guard(path: Path) -> bool:
    """顶层没有可收集测试的 test 文件 = 脚本式守卫。读不出/解析不了的交给 pytest 原路报错。"""
    name = path.name
    if not (name.startswith("test-") or name.startswith("test_")) or path.suffix != ".py":
        return False
    try:
        tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
    except (OSError, SyntaxError, UnicodeDecodeError):
        return False
    return not _has_collectable_tests(tree)


class ScriptGuardItem(pytest.Item):
    def runtest(self) -> None:
        try:
            proc = subprocess.run(
                [sys.executable, str(self.path)],
                cwd=ROOT,
                capture_output=True,
                text=True,
                timeout=SCRIPT_GUARD_TIMEOUT_S,
            )
        except subprocess.TimeoutExpired as exc:
            raise ScriptGuardFailure(f"超时（>{SCRIPT_GUARD_TIMEOUT_S}s）：{exc}") from None
        if proc.returncode != 0:
            raise ScriptGuardFailure(
                f"脚本式守卫退出码 {proc.returncode}\n--- stdout ---\n{proc.stdout}"
                f"\n--- stderr ---\n{proc.stderr}"
            )

    def repr_failure(self, excinfo, style=None):  # noqa: D401 - pytest hook signature
        if isinstance(excinfo.value, ScriptGuardFailure):
            return str(excinfo.value)
        return super().repr_failure(excinfo, style=style)

    def reportinfo(self):
        return self.path, None, f"script-guard {self.path.name}"


class ScriptGuardFailure(Exception):
    pass


class ScriptGuardFile(pytest.File):
    def collect(self):
        yield ScriptGuardItem.from_parent(self, name="script_guard")


def pytest_pycollect_makemodule(module_path: Path, parent):
    if is_script_guard(Path(module_path)):
        return ScriptGuardFile.from_parent(parent, path=Path(module_path))
    return None
