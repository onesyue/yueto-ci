### Two-stage rollout for check-in traffic settlement

The panel_ledger ACK consumer reads the original byte-allocation plan in reward-anchor `metadata.traffic_settlement_v1`. It validates subject, reference, idempotency key and actual receipt range, then updates every row and marks the outbox done in one transaction. Invalid plans must not fall back to single-row allocation. The plan is server-only, excluded from Board wire and user responses; existing single-row semantics for other producers stay unchanged.

Release consumer-only first, keeping the old check-in producer. Read back the images for checkin-api's resident worker and yue-bot's watch consumer, including exit of the old processes, before releasing the producer. Native service order is web → checkin → bot; **do not skip the intermediate consumer-only release**. Producer rollback must target consumer-only. While new-format work is unfinished, do not downgrade to an old consumer that cannot process it.

The producer creates all reward rows in one transaction, then links `outbox.reward_ledger_id` to the first traffic row. Plan-request bytes and Board payload use the same integer. Four-decimal GB amounts use differences between cumulative actual values; `metadata.applied_bytes` retains exact bytes.

Public `POST /auth/login` password validation is only the first factor and returns `{second_factor_required:true, second_factor:"board_sso"}`, **without issuing a session**. Accounts without `board_user_id` return403 `second_factor_unavailable`. Bastion loopback with no `CF-Connecting-IP` is the password-only emergency entry, returning `{access_token, must_change_password}`. `POST /auth/change-password` accepts `{old_password,new_password}` (≥8 characters).
- WS `/api/tasks/{id}/ws` accepts the token only in `Sec-WebSocket-Protocol`, never the query string.
- Trust X-Forwarded-For only when `request.client.host` is127.0.0.1 or`::1`.

# Guard authoring (Yue.to)

The expensive failure is a green guard protecting nothing. The linked incident examples
occurred in actual production work.

Apply the checklist to the guard's actual inputs, dependencies and claimed
coverage. Running an existing check does not require redesigning it. A changed
assertion, scan boundary or success/failure classification does require this skill.
For import/fixture leakage, load [test isolation](references/test-isolation.md)
first; use the guard checklist only if guard coverage changes.

Before adding an invariant, establish which consumer needs it and check its
actual semantics. Challenge it with one realistic counterexample at that boundary:
subprocess execution for locks, a write failure for persistence, or raw single-target
output for collectors. Matching strings or unrelated runner-image labels cannot
establish those properties. Reuse the recorded interpreter/image, user and mounts;
classify failures as startup, collection or assertion before editing product code.

## Establish three facts before accepting green

1. Did this run reach the target? Zero executions is not a pass.
2. Did the scan cover the intended objects? Zero matches is not universal success.
3. Is the guarded layer the layer users and production actually encounter?

A negative answer makes the green result meaningless.

## Load only the relevant incident reference

Keep the common criteria and checklist below for guard changes. Read a reference
only when its failure class applies; the catalog is retained evidence, not an
extra audit assignment.

| Observed problem | Reference |
|---|---|
| A check never executes, scans nothing, targets the wrong layer, hides failure, or has no legitimate success path | [Coverage failures](references/coverage-failures.md), numbered incidents 1–9 |
| Wrong interpreter or checkout, SSH stdin, toolchain drift, signed installation closure, systemd results, incomplete pagination or runtime budgets | [Execution boundaries](references/execution-boundaries.md) |
| Import/fixture pollution, swallowed real I/O timeouts, fork deadlocks or teardown order | [Test isolation](references/test-isolation.md) |

## Required guard-delivery checklist

- [ ] Remove/rename/delete the protected object in an isolated mutation: the
  guard must fail, not mistake missing input for correctness.
- [ ] Exercise dependency failures the guard can encounter: wrong credentials
  for authenticated probes, network failure for remote probes, and permission
  failure for protected inputs. Verify their visible classifications.
- [ ] For scans, require a minimum target count; for a single target, prove arrival.
- [ ] Before counting negative observations, prove target-handler arrival and
  run controls protecting legitimate behavior.
- [ ] Register cross-repository guards in `scripts/check-all-contracts.sh`.
  `<path>` must name the sibling file actually read, not the guard script itself;
  otherwise missing-repository SKIP is unreachable. `guard-ci-claims` enforces it.
- [ ] Enumerate every criterion dimension, such as status × amount × ownership.
- [ ] Never duplicate live fleet counts. Since 2026-09-14, derive them from
  `servers.deploy_mode='direct'`; node-control-auth-migrate.py EXPECTED baselines
  no longer exist. Documentation may retain dated snapshots. Only mechanically
  enforced authoritative projections and date-anchored observations are exceptions.

## Workspace-only guards

`scripts/check-all-contracts.sh` alone knows the complete cross-repository guard
set. Single-repo CI cannot see all private siblings; a green component does not
establish a shared contract. The registry explicitly states whether a component
CI consumer exists.

A 2026-08-02 isolated Ops checkout showed whole tests skipped in ci-backend.yml:
`panel-deep-links` (2), `idempotency-catalog` (5, module-level pytestmark),
`registry-links` (2), and cross-surface design-token-gate cases. These and the
root scripts-level comparators run only in the workspace. Run the contract script
before pushing cross-repository changes.

`guard-ci-claims` (`scripts/check-guard-ci-claims.py`) fails when sibling-dependent
entries lack workspace-only marking or claimed component CI lacks a workflow
execution path. Missing repositories must report SKIP; `<path>` identifies the
actual sibling input, never the guard itself, so missing input cannot appear PASS.

`scripts/gauntlet.sh` similarly turns a former verbal pre-release promise into
execution: missing tools/repos are SKIP, never PASS, and too few actually executed
stages fail the gate.

+    """Mask comments and string/dollar literals before reading static DDL.
+
+    Procedural bodies are opaque: never infer a DROP from a function definition
+    or dynamic SQL. This inventory does not execute conditional migrations.
+    """
+    tokens = re.compile(r"--[^\n]*|/\*|[Ee]'(?:\\.|''|[^'\\])*'|'(?:[^']|'')*'|\$(?:[a-z_][a-z0-9_]*)?\$", re.I)
+    result, start = [], 0
+    while match := tokens.search(text, start):
+        result.append(text[start:match.start()])
+        token = match.group()
+        end = match.end()
+        if token == "/*":
+            depth = 1
+            while depth:
+                marker = re.search(r"/\*|\*/", text[end:])

Before delivery, establish all three properties:

1. **It fails when the protected fact is broken.** Run a mutation test; without
   this, the guard is not delivered.

def parse_grants(sql):
    acl = defaultdict(set)
    for match in GRANT.finditer(uncomment(sql)):
        privileges, tables, roles = match.groups()
        for op, columns in re.findall(r"(SELECT|INSERT|UPDATE|DELETE|ALL(?:\s+PRIVILEGES)?)\s*(?:\(([^)]*)\))?", privileges, re.I):
            for role in roles.replace(" ", "").replace("\n", "").split(","):
                for table in tables.split(","):
                    for privilege in ("SELECT", "INSERT", "UPDATE", "DELETE") if op.upper().startswith("ALL") else (op.upper(),):

                            c.strip().strip('"') for c in columns.split(",") if c.strip()
                        ) if columns else acl[role, table.strip().removeprefix("public."), privilege].add("*")
    return acl

        # The least-privilege policy revokes shared-table writes outside users.

        assert len(shared) >= 25
        assert "keep text[] := ARRAY['users']" in read("scripts/sql/pg-least-privilege-yue-to.sql")
        for table in shared - {"users"}:

                acl[table, op] = set()
    if service.role == "app_yueboard":
        manifest = uncomment(read(service.policy))
        for table, ops, _required in re.findall(r"\('([a-z_]+)',\s*'([A-Z,]+)',\s*(true|false)\)", manifest):
            for op in ops.split(","):

def fold(node, constants):
    if isinstance(node, ast.Constant) and isinstance(node.value, str):
        return node.value
    if isinstance(node, ast.Name):
        return constants.get(node.id, "{dynamic}")
    if isinstance(node, ast.JoinedStr):
        return "".join(fold(v.value, constants) if isinstance(v, ast.FormattedValue) else fold(v, constants) for v in node.values)
    if isinstance(node, ast.BinOp) and isinstance(node.op, ast.Add):
        return fold(node.left, constants) + fold(node.right, constants)
    return "{dynamic}"


def sources(service):
    for name in service.paths:
        root = ROOT / name
        assert root.exists(), name
        paths = sorted(root.rglob("*.py")) if root.is_dir() else [root]
        for path in paths:
            # This subtree uses TELEMETRY_DATABASE_DSN (yueops), not ck_db's
            # app_checkin connection to yue-to. Its env-selected role is unknown.
            if service.role == "app_checkin" and "telemetry" in path.relative_to(ROOT).parts:
                continue
            if "tests" in path.parts or path.name.startswith("test_"):
                continue
            source = path.read_text(encoding="utf-8")
            if path.suffix != ".py":
                yield str(path.relative_to(ROOT)), source
                continue
            tree = ast.parse(source)
            parent = {id(child): n for n in ast.walk(tree) for child in ast.iter_child_nodes(n)}
            constants = {}
            for node in tree.body:
                if isinstance(node, ast.Assign) and isinstance(node.targets[0], ast.Name):
                    constants[node.targets[0].id] = fold(node.value, constants)
            parents = {id(child) for n in ast.walk(tree) if isinstance(n, (ast.BinOp, ast.JoinedStr)) for child in ast.walk(n) if child is not n}
            for node in ast.walk(tree):
                if isinstance(node, (ast.Constant, ast.JoinedStr, ast.BinOp)) and id(node) not in parents:
                    sql = fold(node, constants)
                    ancestors = []
                    current = node
                    while id(current) in parent:
                        current = parent[id(current)]
                        ancestors.append(current)
                    if service.role == "yueboard_node_auth_migrator" and any(
                        isinstance(a, ast.Assign) and any(isinstance(t, ast.Name) and t.id == "DIRECT_INVENTORY_QUERY" for t in a.targets)
                        for a in ancestors
                    ):
                        continue
                    if "retirement_auditor" in service.role:
                        calls = [a for a in ancestors if isinstance(a, ast.Call) and isinstance(a.func, ast.Attribute) and a.func.attr == "_psql"]
                        prefix = "YUEOPS_RETIRE_DB" if service.database == "yueops" else "YUEBOARD_RETIRE_DB"
                        if not calls or not calls[0].args or fold(calls[0].args[0], constants) != prefix:
                            continue
                    if re.search(r"\b(SELECT|INSERT|UPDATE|DELETE)\b", sql):
                        yield f"{path.relative_to(ROOT)}:{node.lineno}", sql


IDENT = r'[a-z_][a-z_0-9]*'


# Names that exist only as CTEs in fleet SQL (no relation of that name is
# created in any SQL file). Only these are ever dropped, and only from SQL that
# declares them as a CTE, so every real-table requirement is kept.
CTE_ONLY_RELATIONS = frozenset({"eligible_servers"})


def requirements(sql):
    """Column requirements on real relations; known CTE-only names are not tables."""
    declared = {name.lower() for name in re.findall(
        r"(?:\bWITH(?:\s+RECURSIVE)?|,)\s*(" + IDENT + r")\s+AS\s+(?:NOT\s+)?(?:MATERIALIZED\s+)?\(",
        uncomment(sql), re.I)} & CTE_ONLY_RELATIONS
    for table, op, col in _requirements(sql):
        if table.lower() not in declared:
            yield table, op, col


def test_cte_only_relations_are_not_real_relations():
    pattern = re.compile(r"\b(?:CREATE|ALTER)\s+(?:TABLE|VIEW|MATERIALIZED\s+VIEW)\s+(?:IF\s+NOT\s+EXISTS\s+)?(?:public\.)?(" + IDENT + r")\b", re.I)
    defined = set()
    for path in ROOT.rglob("*.sql"):
        defined |= {m.lower() for m in pattern.findall(path.read_text(errors="replace"))}
    assert defined and not (CTE_ONLY_RELATIONS & defined)


def test_requirements_drop_only_known_cte_names():
    assert set(requirements(
        "WITH eligible_servers AS MATERIALIZED (SELECT sid FROM servers) SELECT sid FROM eligible_servers"
    )) == {("servers", "SELECT", "sid")}
    assert ("users", "SELECT", "last_login_ip") in set(requirements(
        "WITH users AS (SELECT last_login_ip FROM users) SELECT last_login_ip FROM users"))
    assert ("users", "SELECT", "last_login_ip") in set(requirements(
        "SELECT '$$' AS note, last_login_ip FROM users WHERE email = '$$'"))
    assert ("eligible_servers", "SELECT", "sid") in set(requirements("SELECT sid FROM eligible_servers"))


@pytest.mark.parametrize("sql", [

    }

        "x AS (WITH servers AS (SELECT sid FROM servers) SELECT derived FROM servers) "

    )) == {("servers", "SELECT", "sid")}


def _requirements(sql):
    """Extract only unambiguous explicit projection/target column lists.

    General expressions and predicates remain gaps, not guessed identifiers.
    Qualified references require a unique explicit AS alias in the SQL string.
    """
    sql = uncomment(sql)
    # A CTE is a query result, not a separately granted table. Its defining
    # SELECT is scanned below, so source-table requirements remain enforced.
    scrubbed = re.sub(r"'(?:[^']|'')*'", "''", sql)
    cte_scopes = defaultdict(list)
    for cte in re.finditer(
        r'(?:\bWITH\s+|,\s*)(' + IDENT
        + r')\s*(?:\([^)]*\))?\s+AS\s+(?:NOT\s+)?(?:MATERIALIZED\s+)?\(',
        scrubbed, re.I,
    ):
        depth = 1
        for end in range(cte.end(), len(scrubbed)):
            depth += (scrubbed[end] == "(") - (scrubbed[end] == ")")
            if depth == 0:
                # Visibility starts after this non-recursive definition and
                # stops at the enclosing query's closing parenthesis or the
                # statement boundary. Nested definitions cannot escape it.
                scope_end = len(scrubbed)
                for pos in range(end + 1, len(scrubbed)):
                    char = scrubbed[pos]
                    if char == ";" or (char == ")" and depth == 0):
                        scope_end = pos
                        break
                    depth += (char == "(") - (char == ")")
                cte_scopes[cte[1].lower()].append((end, scope_end))
                break
    # Keep offsets aligned after removing literal contents.
    sql = scrubbed
    def derived_reference(table, schema, offset):
        return not schema and any(
            end < offset < scope_end
            for end, scope_end in cte_scopes.get(table.lower(), ())
        )

    for m in re.finditer(r"\bSELECT\s+((?:(?!\bSELECT\b).)*?)\s+FROM\s+(public\.)?(" + IDENT + r")\b", sql, re.I | re.S):
        projection, schema, table = m.groups()
        if derived_reference(table, schema, m.start()) or re.search(r"\bSELECT\b", projection, re.I):
            continue
        alias_match = re.match(r"\s+(?:AS\s+)?(" + IDENT + r")\b", sql[m.end():], re.I)
        alias = alias_match[1] if alias_match else table
        for item in projection.split(","):
            item = re.sub(r"^\s*" + re.escape(alias) + r"\.", "", item)
            col = re.fullmatch(r'\s*(?:DISTINCT\s+)?("?' + IDENT + r'"?)\s*(?:AS\s+' + IDENT + r')?\s*', item, re.I)
            if col and col[1].upper() not in {"NULL", "TRUE", "FALSE", "NOT"}:
                yield table, "SELECT", col[1].strip('"')
    # Single-table predicates have unambiguous attribution. Other SQL shapes
    # remain listed gaps; literals and bound parameter names are not columns.
    refs = re.findall(r"\bFROM\s+(?:public\.)?(" + IDENT + r")\b", sql, re.I)
    if len(refs) == 1 and not re.search(r"\b(JOIN|WITH|UNION|INSERT|UPDATE|DELETE)\b", sql, re.I):
        tail = re.split(r"\bWHERE\b", sql, maxsplit=1, flags=re.I)
        if len(tail) == 2:
            predicates = re.sub(r"\b[a-z_]+\s*=>", " ", tail[1], flags=re.I)
            predicates = re.sub(r"'(?:[^']|'')*'|%\([^)]+\)s|%s|:[a-z_]+", " ", predicates, flags=re.I)
            for col in re.findall(r"(?<![.:])\b(" + IDENT + r")\s*(?==|<>|>=|<=|>|<|\bIS\b|\bIN\b|\bLIKE\b)", predicates, re.I):
                if col.upper() not in {"NULL", "TRUE", "FALSE", "NOT"}:
                    yield refs[0], "SELECT", col
    # Qualified references in projections/predicates/joins are attributable
    # when the alias maps to exactly one relation throughout this SQL string.
    aliases = defaultdict(set)
    for ref in re.finditer(r"\b(?:FROM|JOIN)\s+(public\.)?(" + IDENT + r")\s+AS\s+(" + IDENT + r")", sql, re.I):
        schema, table, alias = ref.groups()
        if not derived_reference(table, schema, ref.start()):
            aliases[alias].add(table)
    scrubbed = re.sub(r"'(?:[^']|'')*'", " ", sql)
    for alias, col in re.findall(r"\b(" + IDENT + r")\.(" + IDENT + r")\b", scrubbed):
        if len(aliases[alias]) == 1:
            yield next(iter(aliases[alias])), "SELECT", col
    for m in re.finditer(r"\bINSERT\s+INTO\s+(?:public\.)?(" + IDENT + r")\s*\(([^)]+)\)", sql, re.I):
        for col in m[2].split(","):
            if re.fullmatch(IDENT, col.strip()):
                yield m[1], "INSERT", col.strip()
    for m in re.finditer(r"\bUPDATE\s+(?:public\.)?(" + IDENT + r")\s+SET\s+(.*?)(?:\bWHERE\b|\bRETURNING\b|;|$)", sql, re.I | re.S):
        for col in re.findall(r"(?:^|,)\s*(" + IDENT + r")\s*=", m[2]):
            yield m[1], "UPDATE", col

    for table in re.findall(r"\bDELETE\s+FROM\s+(?:public\.)?(" + IDENT + r")\b", sql, re.I):
        yield table, "DELETE", "*"


@lru_cache(None)
def inventory(service):
    acl = policy(service)
    checked, unknown = set(), set()
    tables = {table for table, _ in acl}
    for site, sql in sources(service):
        for table, op, column in requirements(sql):
            # Multi-DSN operational scripts and web: only the tables in this
            # connection's policy can be assigned without dataflow analysis.
            if service.role not in {"app_checkin", "app_yue_bot"} and table not in tables:
                unknown.add((site, table, op, column))
                continue
            if "auditor" in service.role and op != "SELECT":
                continue
            if service.role == "app_yueops_web_bot_ro" and op != "SELECT":
                continue
            allowed = acl.get((table, op))
            closed = bool(service.policy) or table == "users" or (
                service.role == "app_yue_bot" and table == "orders"
            ) or allowed == set()
            covered = allowed is not None and (closed or "*" in allowed or column in allowed)
            target = checked if covered else unknown
            target.add((site, table, op, column))
    return checked, unknown


def missing(service):
    acl = policy(service)
    return sorted(item for item in inventory(service)[0]
                  if "*" not in acl[item[1], item[2]] and item[3] not in acl[item[1], item[2]])

def live_check(connection, service):
    with connection.cursor() as cur:
        cur.execute("SHOW transaction_read_only")
        assert cur.fetchone()[0] == "on", "live ACL session must be read-only"
        cur.execute("SELECT EXISTS (SELECT 1 FROM pg_roles WHERE rolname=%s)", (service.role,))
        assert cur.fetchone()[0], f"missing role {service.role}"
        # Include concrete policy grants for external consumers. Unresolved
        # connection/table attribution stays a gap, not a fabricated live probe.
        needs = {(t, op, c) for _, t, op, c in inventory(service)[0]}
        if not service.paths:
            needs = {(t, op, c) for (t, op), cols in policy(service).items() for c in cols}
        if service.role == "app_yueops":
            # ORM mapping supplies table names without importing web/database.
            for table in re.findall(r'__tablename__ = "([a-z_]+)"', read("web/models.py")):
                cur.execute("SELECT has_table_privilege(%s,%s,'SELECT')", (service.role, "public." + table))
                assert cur.fetchone()[0], f"app_yueops: {table} SELECT"
            return
        if service.role == "yueops_support_maintenance":
            cur.execute("SELECT has_function_privilege(%s,%s,'EXECUTE')", (service.role, "yueops_maintenance.archive_stale_support_threads()"))
            assert cur.fetchone()[0], "maintenance function EXECUTE missing"
            return
        if service.role == "app_yueboard_migrator":
            cur.execute("SELECT pg_has_role(%s,'yueboard_migrator','MEMBER')", (service.role,))
            assert cur.fetchone()[0], "migrator owner membership missing"
            return
        if service.role == "app_exporter":
            cur.execute("SELECT has_table_privilege(%s,'pg_catalog.pg_stat_database','SELECT')", (service.role,))
            assert cur.fetchone()[0], "exporter cannot read pg_stat_database"
            return
        if not needs:
            pytest.skip("Role exists; table privileges uncovered: " + service.gap)
        for table, op, col in sorted(needs):
            cur.execute("SELECT to_regclass(%s)", ("public." + table,))
            assert cur.fetchone()[0], f"{service.role}: missing table {table}"
            cur.execute("SELECT has_table_privilege(%s,%s,%s)", (service.role, "public." + table, op))
            allowed = cur.fetchone()[0]
            if not allowed and col != "*" and op != "DELETE":
                cur.execute("SELECT has_column_privilege(%s,%s,%s,%s)", (service.role, "public." + table, col, op))
                allowed = cur.fetchone()[0]
            assert allowed, f"{service.role}: {table}.{col} {op}"

@pytest.mark.parametrize("readonly,allowed", [(False, True), (True, False), (True, True)])
def test_live_probe_reaches_privilege_check_and_rejects_denial(readonly, allowed):
    class Cursor:
        def __init__(self):
            self.calls = []
            self.answer = None

        def __enter__(self):
            return self

        def __exit__(self, *args):
            pass

        def execute(self, query, args=None):
            self.calls.append(query)
            if query.startswith("SHOW"):
                self.answer = "on" if readonly else "off"
            elif "has_table_privilege" in query:
                self.answer = allowed if args[-1] == "DELETE" else False
            elif "has_column_privilege" in query:
                self.answer = allowed
            else:
                self.answer = True

        def fetchone(self):
            return (self.answer,)

    class Connection:
        def __init__(self):
            self.cur = Cursor()

        def cursor(self):
            return self.cur

    connection = Connection()
    if readonly and allowed:
        live_check(connection, SERVICES[0])
        assert any("has_column_privilege" in q for q in connection.cur.calls)
        assert any("has_table_privilege" in q for q in connection.cur.calls)
    else:
        with pytest.raises(AssertionError):
            live_check(connection, SERVICES[0])

回答：「这张表还有没有代码在用？」—— 判据是源码里有没有针对它的 SQL

def _dynamic_sql_user(table: str) -> bool:
    rel = DYNAMIC_SQL_TABLES.get(table)
    if not rel:
        return False
    path = ROOT / rel
    if not path.is_file():
        return False
    text = path.read_text(encoding="utf-8", errors="ignore")
    return f'"{table}"' in text or f"'{table}'" in text


def _migration_sql(text: str) -> str:
    """Mask comments and string/dollar literals before reading static DDL.

    Procedural bodies are opaque: never infer a DROP from a function definition
    or dynamic SQL. This inventory does not execute conditional migrations.
    """
    tokens = re.compile(r"--[^\n]*|/\*|[Ee]'(?:\\.|''|[^'\\])*'|'(?:[^']|'')*'|\$(?:[a-z_][a-z0-9_]*)?\$", re.I)
    result, start = [], 0
    while match := tokens.search(text, start):
        result.append(text[start:match.start()])
        token = match.group()
        end = match.end()
        if token == "/*":
            depth = 1
            while depth:
                marker = re.search(r"/\*|\*/", text[end:])
                if marker is None:
                    raise ValueError("unterminated migration comment")
                depth += 1 if marker.group() == "/*" else -1
                end += marker.end()
        elif token.startswith("$"):
            close = text.find(token, end)
            if close < 0:
                raise ValueError("unterminated migration dollar literal")
            end = close + len(token)
        result.append(" ")
        start = end
    result.append(text[start:])
    return "".join(result)


def created_tables() -> dict[str, str]:
    """Surviving table name -> creation migration, after ordered DROP statements.

    This is the repository migration lifecycle, not proof of applied production
    state. SQL comments and string literals must not execute rollback examples.
    """
    out: dict[str, str] = {}
    statements = re.compile(
        r"(?P<create>CREATE TABLE(?:\s+IF NOT EXISTS)?\s+(?P<created>[a-z_][a-z0-9_]*))"
        r'|(?P<drop>DROP TABLE(?:\s+IF EXISTS)?\s+(?:public\.)?"?(?P<dropped>[a-z_][a-z0-9_]*)"?)',
        re.I | re.S,
    )
    for path in sorted(MIGRATIONS.glob("*.sql")):
        text = path.read_text(encoding="utf-8", errors="ignore")
        for match in statements.finditer(_migration_sql(text)):
            if match.group("create"):
                out.setdefault(match.group("created").lower(), path.name)
            elif match.group("drop"):
                out.pop(match.group("dropped").lower(), None)
    return out


def scan_sources() -> list[tuple[Path, str]]:
    """全仓源码（**不含迁移目录本身** —— 建表语句不算「有人在用」）。"""
    files: list[tuple[Path, str]] = []
    for rel in SCAN_ROOTS:
        root = ROOT / rel
        if not root.is_dir():
            continue
        for path in root.rglob("*"):
            if path.suffix not in SCAN_SUFFIXES:
                continue
            if {"__pycache__", "node_modules", ".venv"} & set(path.parts):
                continue
            if path.is_relative_to(MIGRATIONS):
                continue
            files.append((path, path.read_text(encoding="utf-8", errors="ignore")))
    return files


def find_orphans() -> tuple[dict[str, str], int, int]:
    """返回 (孤儿表 → 建它的迁移, 扫到的表数, 扫到的文件数)。"""
    tables = created_tables()
    files = scan_sources()
    orphans: dict[str, str] = {}
    for table, origin in sorted(tables.items()):
        pattern = re.compile(_SQL_REF.format(re.escape(table)), re.I)
        if not any(pattern.search(text) for _path, text in files) and not _dynamic_sql_user(table):
            orphans[table] = origin
    return orphans, len(tables), len(files)

def _requirements(sql):
    """Extract only unambiguous explicit projection/target column lists.

    General expressions and predicates remain gaps, not guessed identifiers.
    Qualified references require a unique explicit AS alias in the SQL string.
    """
    sql = uncomment(sql)
    # A CTE is a query result, not a separately granted table. Its defining
    # SELECT is scanned below, so source-table requirements remain enforced.
    scrubbed = re.sub(r"'(?:[^']|'')*'", "''", sql)
    cte_scopes = defaultdict(list)
    for cte in re.finditer(
        r'(?:\bWITH\s+|,\s*)(' + IDENT
        + r')\s*(?:\([^)]*\))?\s+AS\s+(?:NOT\s+)?(?:MATERIALIZED\s+)?\(',
        scrubbed, re.I,
    ):
        depth = 1
        for end in range(cte.end(), len(scrubbed)):
            depth += (scrubbed[end] == "(") - (scrubbed[end] == ")")
            if depth == 0:
                # Visibility starts after this non-recursive definition and
                # stops at the enclosing query's closing parenthesis or the
                # statement boundary. Nested definitions cannot escape it.
                scope_end = len(scrubbed)
                for pos in range(end + 1, len(scrubbed)):
                    char = scrubbed[pos]
                    if char == ";" or (char == ")" and depth == 0):
                        scope_end = pos
                        break
                    depth += (char == "(") - (char == ")")
                cte_scopes[cte[1].lower()].append((end, scope_end))
                break
    # Keep offsets aligned after removing literal contents.
    sql = scrubbed
    def derived_reference(table, schema, offset):
        return not schema and any(
            end < offset < scope_end
            for end, scope_end in cte_scopes.get(table.lower(), ())
        )

    for m in re.finditer(r"\bSELECT\s+((?:(?!\bSELECT\b).)*?)\s+FROM\s+(public\.)?(" + IDENT + r")\b", sql, re.I | re.S):
        projection, schema, table = m.groups()
        if derived_reference(table, schema, m.start()) or re.search(r"\bSELECT\b", projection, re.I):
            continue
        alias_match = re.match(r"\s+(?:AS\s+)?(" + IDENT + r")\b", sql[m.end():], re.I)
        alias = alias_match[1] if alias_match else table
        for item in projection.split(","):
            item = re.sub(r"^\s*" + re.escape(alias) + r"\.", "", item)
            col = re.fullmatch(r'\s*(?:DISTINCT\s+)?("?' + IDENT + r'"?)\s*(?:AS\s+' + IDENT + r')?\s*', item, re.I)
            if col and col[1].upper() not in {"NULL", "TRUE", "FALSE", "NOT"}:
                yield table, "SELECT", col[1].strip('"')
    # Single-table predicates have unambiguous attribution. Other SQL shapes
    # remain listed gaps; literals and bound parameter names are not columns.
    refs = re.findall(r"\bFROM\s+(?:public\.)?(" + IDENT + r")\b", sql, re.I)
    if len(refs) == 1 and not re.search(r"\b(JOIN|WITH|UNION|INSERT|UPDATE|DELETE)\b", sql, re.I):
        tail = re.split(r"\bWHERE\b", sql, maxsplit=1, flags=re.I)
        if len(tail) == 2:
            predicates = re.sub(r"\b[a-z_]+\s*=>", " ", tail[1], flags=re.I)
            predicates = re.sub(r"'(?:[^']|'')*'|%\([^)]+\)s|%s|:[a-z_]+", " ", predicates, flags=re.I)
            for col in re.findall(r"(?<![.:])\b(" + IDENT + r")\s*(?==|<>|>=|<=|>|<|\bIS\b|\bIN\b|\bLIKE\b)", predicates, re.I):
                if col.upper() not in {"NULL", "TRUE", "FALSE", "NOT"}:
                    yield refs[0], "SELECT", col
    # Qualified references in projections/predicates/joins are attributable
    # when the alias maps to exactly one relation throughout this SQL string.
    aliases = defaultdict(set)
    for ref in re.finditer(r"\b(?:FROM|JOIN)\s+(public\.)?(" + IDENT + r")\s+AS\s+(" + IDENT + r")", sql, re.I):
        schema, table, alias = ref.groups()
        if not derived_reference(table, schema, ref.start()):
            aliases[alias].add(table)
    scrubbed = re.sub(r"'(?:[^']|'')*'", " ", sql)
    for alias, col in re.findall(r"\b(" + IDENT + r")\.(" + IDENT + r")\b", scrubbed):
        if len(aliases[alias]) == 1:
            yield next(iter(aliases[alias])), "SELECT", col
    for m in re.finditer(r"\bINSERT\s+INTO\s+(?:public\.)?(" + IDENT + r")\s*\(([^)]+)\)", sql, re.I):
        for col in m[2].split(","):
            if re.fullmatch(IDENT, col.strip()):
                yield m[1], "INSERT", col.strip()
    for m in re.finditer(r"\bUPDATE\s+(?:public\.)?(" + IDENT + r")\s+SET\s+(.*?)(?:\bWHERE\b|\bRETURNING\b|;|$)", sql, re.I | re.S):
        for col in re.findall(r"(?:^|,)\s*(" + IDENT + r")\s*=", m[2]):
            yield m[1], "UPDATE", col

    for table in re.findall(r"\bDELETE\s+FROM\s+(?:public\.)?(" + IDENT + r")\b", sql, re.I):
        yield table, "DELETE", "*"


@lru_cache(None)
def inventory(service):
    acl = policy(service)
    checked, unknown = set(), set()
    tables = {table for table, _ in acl}
    for site, sql in sources(service):
        for table, op, column in requirements(sql):
            # Multi-DSN operational scripts and web: only the tables in this
            # connection's policy can be assigned without dataflow analysis.
            if service.role not in {"app_checkin", "app_yue_bot"} and table not in tables:
                unknown.add((site, table, op, column))
                continue
            if "auditor" in service.role and op != "SELECT":
                continue
            if service.role == "app_yueops_web_bot_ro" and op != "SELECT":
                continue
            allowed = acl.get((table, op))
            closed = bool(service.policy) or table == "users" or (
                service.role == "app_yue_bot" and table == "orders"
            ) or allowed == set()
            covered = allowed is not None and (closed or "*" in allowed or column in allowed)
            target = checked if covered else unknown
            target.add((site, table, op, column))
    return checked, unknown


def missing(service):
    acl = policy(service)
    return sorted(item for item in inventory(service)[0]
                  if "*" not in acl[item[1], item[2]] and item[3] not in acl[item[1], item[2]])

# Change blast radius (Yue.to)

Removals and renames are more dangerous than additions in this workspace. It is
not a monorepo: five surfaces, four runtimes, guards and historical reviews can
all pin one value. **Missing a dependent consumer is the danger**: the overlooked
consumer will fail closed on the next release.

Use `generated-blocks` for design tokens, copy and schedules, and `node-lifecycle`
for node retirement. This skill covers **every removal, rename, move or reset to
zero**.

## Before editing, enumerate everything that pins the value

```bash
rg -n '<name-to-remove>' .                          # Entire workspace, not just this repo.
rg -n 'readonly EXPECTED_[A-Z]*=[0-9]'              # Pinned cardinality constants.
```

Measured examples: removing one "permanent exclusion" touched **70 files**.
Retiring two hosts exposed 8 old cardinality assertions, including two that
**blocked image rollout** with `exit 64`.

## 1. Renaming does not remove an obsolete prerequisite

After device credentials were removed, the startup gate
`deviceCredentialMatchesInstallation` was renamed to `accountProfileIsUsable`
and retained. The former credential was now the only correct one, but the gate
**rejected what it should have accepted** and the app could not connect. Its
message referred to a feature that no longer existed, hiding the cause.

A gate whose prerequisite disappears can become an **inverted gate**, not a
relaxed one. Diagnostic events such as `start_blocked <removed-feature>_pending`
are a warning. For each place being changed rather than removed, ask whether
its prerequisite still exists. If not, remove it instead of preserving it by
renaming.

## 2. Zero may disable a limit instead of tightening it

One documented "emergency stop" actually released the limit: all three caps
used `if cap > 0 and ...`, so **zero disabled the loss limit**. A zero exchange
rate passed through `max(1, ...)` and increased generosity tenfold.

Before assuming that a smaller value or zero is safer, read its sentinel
semantics: `> 0`, `max(1,…)`, `or default`, `if not x`. A related trap is Go
`float64→int64` overflow: behavior differs by architecture (arm64 saturation
versus amd64 wraparound). Code that appears safe on a developer machine can
wrap negative in production.

## 3. Moving documentation can silently blind negative guards

Document-truth guards react in two different ways:

- **Positive assertions** ("documentation must say X") fail immediately.
- **Negative assertions** ("documentation must no longer say Y") can silently
  lose most of their scan surface while staying green.

Fixing only the failing assertions leaves a hole. Before moving text, enumerate
all negative guards and extend their corpus to the new location. YueOps'
`tests/_operational_docs.py` includes CLAUDE.md + every SKILL.md with a scan floor.

Similarly, `schedule/registry.yaml` pins `<prefix>:<file>:<callable>` (`#n` when
the same callable is repeated in one file, numbered in source order). A blank
line or comment in an indexed file does not fail
`scripts/schedule/extract.py --check`. Cadence, OnFailure, RandomizedDelaySec,
Persistent, liveness, and frozen status still do. Regenerate with
`scripts/schedule/extract.py --write` when a real schedule change lands.

## 4. Removing a wait requires a destination for "not ready yet"

When removing a wait, define how to handle the prerequisite that has not yet
arrived. Otherwise it becomes an **alert storm**. The incident involving an
8-hour window was not caused by the window itself.

**Update documentation in the same commit as a gate change.** Removed code with
unchanged instructions is equally harmful: planners wait 8 hours unnecessarily
and report work as impossible that evening.

## 5. Prove an exclusion is obsolete with three independent facts

A code comment claiming that the row no longer exists is not evidence. The
measured requirement was: zero excluded rows in the database, the corresponding
panel row inactive with zero assignments, and production runtime evidence
showing `EXCLUDED_SIDS=none`.

## 6. Tests caught two excessive removals

- Deleting whole blocks that contained a keyword removed 6 real tests using the
  SID merely as a string in **synthetic fixtures**. A fixture name is only a name,
  not the object being removed.
- `NODE_MAINTENANCE_RAW_HOSTS/ELIGIBLE_HOSTS` were mistaken for an exclusion
  mechanism. They were **fleet cardinality assertions**, unrelated to exclusion,
  and were renamed `FLEET_EXPECTED_DIRECT_HOSTS` to prevent recurrence.

**Preserve the audit chain.** Keep SID references in historical baseline reviews:
they explain why the baseline had those counts. Remove live obsolete code, not
historical reasoning.

## 7. Equal names or values can have different meanings

- The AI database-writer identity and the definition of a support agent both
  used 1 but meant different things. Changing both made LLM quality checks score
  human replies and generate false alerts.
- Two databases have a table named `kb_documents`; querying the wrong one gave
  the opposite conclusion.
- Historical canonical-evidence baseline changes deadlocked all three writers;
  the prescribed solution then was a dated one-time migrator in the same round.
  Shared-pool membership changes do not change the unique count, a repeatedly
  missed distinction. This historical incident does not reinstate machinery
  retired by the current release chain.

## Pre-change checklist

- [ ] Search the entire workspace for the name/value, not just this repository.
- [ ] Find pinned cardinality constants with `rg -n 'EXPECTED_[A-Z]*=[0-9]'`.
- [ ] Verify prerequisites still exist wherever a gate is changed rather than removed.
- [ ] Read sentinel semantics before setting a value to zero/empty.
- [ ] Enumerate negative guards and move their scan surface with the content.
- [ ] Define a destination for "not ready yet" when removing a wait.
- [ ] Update gate documentation in the same commit.
- [ ] Retain historical reviews and the audit chain.
- [ ] Actually run the preflight. Do not copy a convergence precedent blindly:
  the Cartesian-product incident appeared only during execution, not code review.
