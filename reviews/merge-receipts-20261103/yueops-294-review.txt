### Two-stage rollout for check-in traffic settlement

The panel_ledger ACK consumer reads the original byte-allocation plan in reward-anchor `metadata.traffic_settlement_v1`. It validates subject, reference, idempotency key and actual receipt range, then updates every row and marks the outbox done in one transaction. Invalid plans must not fall back to single-row allocation. The plan is server-only, excluded from Board wire and user responses; existing single-row semantics for other producers stay unchanged.

Release consumer-only first, keeping the old check-in producer. Read back the images for checkin-api's resident worker and yue-bot's watch consumer, including exit of the old processes, before releasing the producer. Native service order is web → checkin → bot; **do not skip the intermediate consumer-only release**. Producer rollback must target consumer-only. While new-format work is unfinished, do not downgrade to an old consumer that cannot process it.

The producer creates all reward rows in one transaction, then links `outbox.reward_ledger_id` to the first traffic row. Plan-request bytes and Board payload use the same integer. Four-decimal GB amounts use differences between cumulative actual values; `metadata.applied_bytes` retains exact bytes.

### Auth API

- **Two-factor login is mandatory (2026-09-26).** Primary entry: YueBoard admin's YueOps console item → `/sso/board` → `POST /auth/board-sso`; Board TOTP/passkey supplies the second factor. Public `POST /auth/login` password validation is only the first factor and returns `{second_factor_required:true, second_factor:"board_sso"}`, **without issuing a session**. Accounts without `board_user_id` return403 `second_factor_unavailable`. Bastion loopback with no `CF-Connecting-IP` is the password-only emergency entry, returning `{access_token, must_change_password}`. `POST /auth/change-password` accepts `{old_password,new_password}` (≥8 characters).
- WS `/api/tasks/{id}/ws` accepts the token only in `Sec-WebSocket-Protocol`, never the query string.
- Trust X-Forwarded-For only when `request.client.host` is127.0.0.1 or`::1`.

# Guard authoring (Yue.to)

The expensive failure is a green guard protecting nothing. The linked incident examples
occurred in actual production work.

Apply the checklist to the guard's actual inputs, dependencies and claimed
coverage. Running an existing check does not require redesigning it. A changed
assertion, scan boundary or success/failure classification does require this skill.
For import/fixture leakage, load [test isolation](references/test-isolation.md)
first; use the guard checklist only if guard coverage changes.

Before adding an invariant, establish which consumer needs it and check its
actual semantics. Challenge it with one realistic counterexample at that boundary:
subprocess execution for locks, a write failure for persistence, or raw single-target
output for collectors. Matching strings or unrelated runner-image labels cannot
establish those properties. Reuse the recorded interpreter/image, user and mounts;
classify failures as startup, collection or assertion before editing product code.

## Establish three facts before accepting green

1. Did this run reach the target? Zero executions is not a pass.
2. Did the scan cover the intended objects? Zero matches is not universal success.
3. Is the guarded layer the layer users and production actually encounter?

A negative answer makes the green result meaningless.

## Load only the relevant incident reference

Keep the common criteria and checklist below for guard changes. Read a reference
only when its failure class applies; the catalog is retained evidence, not an
extra audit assignment.

| Observed problem | Reference |
|---|---|
| A check never executes, scans nothing, targets the wrong layer, hides failure, or has no legitimate success path | [Coverage failures](references/coverage-failures.md), numbered incidents 1–9 |
| Wrong interpreter or checkout, SSH stdin, toolchain drift, signed installation closure, systemd results, incomplete pagination or runtime budgets | [Execution boundaries](references/execution-boundaries.md) |
| Import/fixture pollution, swallowed real I/O timeouts, fork deadlocks or teardown order | [Test isolation](references/test-isolation.md) |

# yueops-deploy-gotchas

> 本文逐字取自 `yueops/CLAUDE.md`，**内容一字未改**——只是从「每次会话都加载」
> 换成「相关时才加载」。这些事实全部来自真实生产事故，删改前先确认它已经不成立。

### 平台/部署

- **datetime** naive UTC `datetime.utcnow()`。
- **🚨 一大批 systemd 单元同时 `status=226/NAMESPACE` → 先看 `/dev/null` 还是不是字符设备**（2026-08-02 bastion 实测）。`ls -l /dev/null` 若是 regular file，则所有带 `PrivateDevices=`/`ProtectSystem=strict` 的单元一律起不来（日志 `Failed to set up mount namespacing: /dev: Inappropriate ioctl for device`，systemd 另有一行 `/dev/null is not a device.`），本次一次性打掉 17 个单元，其中包括 `yue-tg-notify-drain`（**告警自己也发不出去**）和 `direct-pool-dns-reconciler`。修复 `rm -f /dev/null && mknod -m 666 /dev/null c 1 3`（已打开旧 inode 的进程不受影响，无需重启）。**别看文件内容找元凶**：任何 `cmd > /dev/null` 都会把它 truncate 重写，内容只反映最后一个写者（本次是 4 字节 `nvm\n`，纯噪音）。判据是 `stat -c %w`（birth）。
  - **🔎 元凶已定位（2026-08-02 复盘）= `install -m0755 <src> /dev/null`**，root 经 SSH 跑的一条临时运维命令，birth `14:05:52.83` 与它的下发时刻 `14:05:52.228` 相差 0.6s，且全量会话记录里这是唯一一次把 `/dev/null` 放在**目的位**。**机理已在同一台机、同一个 devtmpfs 上复现**：`install` 会先 `unlink` 目的路径再新建常规文件，**默认模式恰好是 0755**——与现场的 `regular file / 0755` 逐位吻合。同类危险动词还有 `mv`、`cp --remove-destination`、`rsync`（都换 inode）；而 `install -m0600 /dev/null "$f"`（`/dev/null` 在**源位**）是安全且常用的建空文件写法，两者只差参数顺序。
  - ⚠️ **owner 那一位没查实**：现场是 uid 65532/gid root，但 `install` 在本机复现出来的是 `0:0`，且 14:05:53–14:25:51 之间找不到任何 chown 到 65532 的东西（ctime 已被 14:27 的 `cp -a ... 2>/dev/null` 覆盖，时刻不可考）。**不要把 uid 65532 当成「容器干的」的证据**——它没有被解释，仅此而已。
  - **守卫 `dev-null-integrity-guard.timer`（5min）**：`stat -c "%F %a %t:%T"` 不等于 `character special file 666 1:3` 即告警 + 自动 `mknod` 修复 + 落凭据 `/var/log/yueops-dev-null-guard.log`；另抓「成片 226/NAMESPACE」这一指纹。🚨 **它的 unit 故意不带任何 mount-namespace 加固项，脚本里也一个 `> /dev/null` 都不许有**——两者都会让守卫和被守护对象一起死；`tests/test_dev_null_integrity_guard.py` 会在被「顺手加固」时让 CI 变红，并顺带禁止全仓再出现把 `/dev/null` 当目的位的写法。
- **NFT**：`nft delete table ... || true`（不用 destroy）；防火墙现由 `yueops-tuning` .deb 拥有（canonical `/etc/nftables.conf` 模板，UDP hop 固定 20000-40000；生成器 `vps_opt_nft.sh` 2026-07-16 已删）。watchdog 内任何 `docker inspect` 必 `timeout 3`（防 nft-boot Before=docker 循环依赖死锁 [[feedback_vps_opt_nft_deadlock]]）。每台必 `nft-boot.service` enabled（现 .deb 包拥有）。
- **🚨 xray geodata 必须单文件挂载** `/home/yue-node/geodata/geoip.dat:/usr/local/bin/geoip.dat:ro`（目录挂载会覆盖二进制）。
- **节点 config.yml 错配**：部署后 `grep -E 'type:|node_id' node-*/config.yml`。容器内 `node_id` 必填 `parent_id IS NULL` 父节点 id。
- **🚨 config.yml 是 instances-only schema（2026-07-29 全队硬切，yue-node `f53cfa6` 起）**：根键白名单只有 `{instances,kernel,cert,log,node,runtime,sync}`，顶层 `panel:` 会被**直接拒绝加载**（容器反复重启，日志 `top-level field "panel" is not allowed`）。解析器是 strict（`KnownFields`），多一个未知键即整份配置作废——`fetch_interval` 已不是 `PanelConfig` 字段，别再写。`health_port`/`health_bind` 必须放在**实例内**。**🚨 `kernel.config_dir` 有意不被实例继承**（"each instance needs unique dir"），写在根级会被静默忽略、实例转而按配置文件目录派生成 `/etc/yue-node`——那是容器只读层，且换了 outbox 根目录等于**换上报实例、计费序列从头开始**，所以它必须写在实例内并固定 `/etc/yue-node/data`。渲染真源 `yueops/deploy.py::_config_yaml`，存量机迁移走 `_migrate_node_config_to_instances`（只从主机现存值重渲染，绝不拿库里的值纠正身份）。**改任何读 config.yml 的解析器都要同时认两种形态**（迁移窗口内必然并存），见 `tests/test_config_parsers_accept_both_schemas_20260729.py`。
- **Watchdog timer 重命名**：同时 disable 旧+删 unit file；oneshot timer 必 `TimeoutSec=30`。**oneshot service 绝不能加 Type=notify drop-in**（假阳性噪音 [[feedback_systemd_notify_oneshot_drift]]）。
- **route.json**：重载 `docker rm -f`+`compose up -d`；`_ensure_route_json()` 先 `test -d` 删。
- **Migration 3 场景**：同 VPS IP 变→tar+recompose / 不同 VPS→full init+deploy / 同 VPS 重装→fresh deploy。迁移前先 `docker rm -f`。
- **Docker pull/compose pull** timeout=600s。批量升级 SCP 静默失败必验证；长连接不稳用 `nohup script.sh &`。
- **server_metrics**：created_at naive UTC，NOW() CST，用 `NOW() AT TIME ZONE 'UTC' - created_at`。`server_sid` varchar，JOIN `s.sid` 不是 `s.id`。
- **并发 scp/ssh**：限 P≤5+失败重试 5 次+10s backoff。
- **SSH passwords**：Fernet 加密前缀 `enc:`，密钥 `.encrypt.key`（MultiFernet 密钥环，第一行为当前钥匙；缺钥匙 fail-closed，绝不自动生成），`yueops/crypto.py decrypt_password()`；审计/迁移/轮换只走 `scripts/yueops-secrets.py`，见 RUNBOOK §9.1。VM reinstall 密码必须由 secret store 随机生成、每机唯一，严禁写入文档。 peer 同 host 一批只 1 防同时 reboot。
- **三服务部署**：根仓 `scripts/ship.sh yueops` → `scripts/deploy-yueops-digests.sh`；
  三个旧单服务部署器已退役，不再保留 systemd/docker 双路径或兼容转发入口。
- **🚨 direct 舰队 Docker 安全目标（2026-09-04）= Docker **29.8.0** + `containerd.io >= 2.3.4` + `containerd-snapshotter: true`**。GHSA-p7v4-vr35-mj6f 的 v2 受影响区间是 `>=2.1.0 <2.2.7` 与 `>=2.3.0 <2.3.4`；2026-09-04 只读取证为 55 台可达机中 44 台受影响、11 台为 2.3.4，`yue-kr` 身份未恢复所以保留 UNKNOWN。direct 升级只走签名 `scripts/fleet-docker-upgrade.sh`：默认闭合实时 raw56/excluded0/eligible56；当且仅当 `yue-kr` 身份仍 UNKNOWN 时，可按当期 runbook 同时给出精确 SID 与长 ACK，启用源码限定的 raw56/excluded1/eligible55/110-slot 隔离模式，不得接受新 host key、替换 SID、添加第二个排除或降低 raw 分母。每机 `apt-get update` 后精确证明三件 Docker 29.8.0 包与 `containerd.io >=2.3.4` 候选在 `apt-cache madison`、按架构冻结六包、双 canary 顺序升级+至少 120 秒浸泡、2–6 台分波、失败停止后续波；每机变更前缓存并校验六个精确旧包，失败自动恢复并重验两槽。node 镜像 digest/revision 以根仓签名 release.yaml 的 desired（P2 §4 A3 起 `scripts/yue-node.image` 投影已删除）为唯一真源，仪式经签名导出里的 `lib/release-yaml.sh` 读 `/var/lib/yueops/fleet-reconcile/release.yaml`。新装/重装不得因 `command -v docker` 成功就跳过安全验收，也禁止重新引入 `curl get.docker.com | sh`。配套混合主机不得套 direct 两槽脚本，须使用独立 support transaction。仓库目标不等于已部署：没有新的 56/0/56/112 或当期签名 56/1/55/110 target audit，不得声称生产已升级；后者也不得声称 `yue-kr` 已升级。
- **🚨 Docker daemon.json invariant**：(1) `log-driver=journald` 时不能写 `max-size/max-file`（dockerd 拒启动）；(2) `containerd-snapshotter: true` 是当前 fleet 标准（Docker 29.x 默认、2026 主流）——**曾经的 `:false` 是 emby 重存储主机历史事故缓解，不适用轻量代理/服务节点**（2026-07-12 实证当前 Docker 29.x 迁移零卡死）。迁移 overlay2→containerd 需重拉镜像+重建容器（volume/bind 数据无关，安全）；**🚨 docker-run 混合主机（如 panel 的 postgres/otel/nginx 独立容器）切驱动会孤立旧容器，迁移前必先从 `/var/lib/docker/containers/*/config.v2.json`+`hostconfig.json` 提取独立容器精确配置**。(3) Docker 29.3.0+ 若真遇 overlay2 卡 activating，逃生门仍是临时 `:false`。[[project_emby_daemon_down_20260528]]
## Protocol architecture

| Role | Protocol | Applicability |
|---|---|---|
| Primary performance | HY2 (apernet-hysteria node-1/) | All A/B direct hosts |
| Primary stability | VLESS-Reality (xray node-2/) | All A/B direct hosts |

A flagship regions: HK/TW/JP/US/SG. B coverage: KR/TH/MY/IN/AE/TR/UK/ES/SE/BR/AU/VN/NG. Former C long-tail IPv6 destinations retired on2026-07-09. A `parent_id` child shares its parent's process and has no separate container/directory. The container's `node_id` is the ID of the parent whose `parent_id IS NULL`.

# Prove that a guard detects a real failure

Before delivery, establish all three properties:

1. **It fails when the protected fact is broken.** Run a mutation test; without
   this, the guard is not delivered.
2. **It checks the actual consumer.** Importability does not establish execution.
   Removing `if __name__ == "__main__"` can leave importlib-based tests green
   while the actual script silently exits without doing work.
3. **It has a legitimate path to success.** A permanently failing guard with no
   valid remediation is ineffective. Silent `return 1`, single instantaneous
   samples and text-only assertions require particular care.

A missing repository is SKIP, never PASS. Each registered `<path>` must identify
the sibling file actually consumed by the guard. Use `~/.venvs/yueto/bin/python`
for pytest; explicitly select `scripts/test-*.py` because their hyphenated names
are not discovered by pytest's default patterns.

Read `guard-authoring` for the incident patterns and mandatory checklist, and
`change-blast-radius` before removing checks or changing boundaries.

+## Superseding a stale PAUSED window (2026-11-03)
+
+A PAUSED receipt for an older revision cannot be forward-completed by minting an
+old strict root: the canonical `MATERIALIZE` block in `docs/RUNBOOK.md` requires
+`origin/master` to equal the requested revision. Nor may an operator enable the
+old timer merely to satisfy `--prepare-upgrade`. The 2026-10-24 window at
+`5919448a…` retained an `8c5c9c9f…` observer whose five-relay scope cannot prove the
+six-relay runtime after `tw-relay-4` registration. These are dated incident facts,
+not a replacement for current inventory validation.
+
+After review, signing and publication of the change, materialize the current
+master strict root using that canonical block. Use the full stale revision from
+the retained receipt filename; do not edit, delete or copy receipts manually:
+
+```bash
+REV=<current-master-40-hex-revision>
+STALE_REV=<paused-window-40-hex-revision>
+ROOT=/var/lib/yueops-release-roots/$REV
+env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin HOME=/root LC_ALL=C \
+  /bin/bash --noprofile --norc -p "$ROOT/scripts/converge-signed-hy2-relay-verifier.sh" \
+  --source-revision "$REV" \
+  --supersede-upgrade SUPERSEDE_SIGNED_HY2_PACKAGE_UPGRADE_2026_11_03 \
+  --supersedes "$STALE_REV"
+```
+
+This L2 operator-triggered transaction requires the clean root launcher, strict
+current signed root, signed stale ancestor, canonical root-private receipt,
+exact stale target hashes, disabled/inactive timer, idle service, and complete
+signed installed predecessor (including its bundle where required). It refuses
+an existing unit transaction or any stale phase other than PAUSED. The retained
+rollback payloads must match that installed predecessor exactly. This proves
+rollback **bytes**, without claiming that the old observer can verify today's
+packages or topology.
+
+The old receipt is durably marked SUPERSEDED with its exact successor before the
+new PAUSED receipt is published. Its original evidence is retained; all actions
+on that old receipt are rejected. A crash between those writes can be resumed
+with the identical supersede command. Once the new receipt exists, resume with
+`--apply CONVERGE_SIGNED_HY2_RELAY_VERIFIER_2026_08_22` at the new root, including
+after a failed proof. A different successor, active timer, changed predecessor,
+unsafe receipt or unknown bytes fail closed.
+
+Supersede continues directly through the existing apply path: the new source
+must prove the complete current relay runtime, then the installed observer must
+pass an actual native Invocation before the timer is enabled. Failed installation
+or verification retains the new receipt and keeps the timer paused. Read back
+COMPLETE, the new source revision, native verification result, enabled/active
+lifecycle and schedulable NextElapse; source installation alone is not completion.
+For rollback, use the new revision's `--abort-upgrade` command above only after
+restoring the old runtime prerequisites: it still requires a real old observer
+PASS. Supersession does not make the historical five-relay observer usable.

"""Durable timer handoff for a signed HY2 package/observer upgrade.

Only the fully verified native converger invokes this helper, under its existing
lifecycle flock. It never edits a timer schedule, resets a failed service, kills
another process, or treats a returned SSH session as a native verification.

def need(value, message):
    if not value:
        raise RuntimeError(message)


def canon(value):
    return (json.dumps(value, sort_keys=True, separators=(",", ":")) + "\n").encode()


def digest(raw):
    return hashlib.sha256(raw).hexdigest()


def trusted(path, *, directory=False):
    for item in (path, *path.parents):
        info = item.lstat()
        is_dir = item != path or directory
        need(
            (stat.S_ISDIR(info.st_mode) if is_dir else stat.S_ISREG(info.st_mode))
            and info.st_uid == info.st_gid == 0
            and not info.st_mode & 0o022,
            "unsafe upgrade evidence path",
        )
        if not is_dir:
            need(info.st_nlink == 1 and info.st_size <= 2 * 1024 * 1024, "unsafe upgrade evidence file")
    return path.read_bytes() if not directory else None


def run(args, *, timeout=30):
    p = subprocess.run(args, stdin=subprocess.DEVNULL, capture_output=True, env=CLEAN, timeout=timeout)
    need(p.returncode == 0, "native command failed: " + args[0])
    need(len(p.stdout) <= 2 * 1024 * 1024, "native output bound exceeded")
    return p.stdout


def show(unit):
    fields = (
        "LoadState,ActiveState,SubState,UnitFileState,MainPID,ControlPID,Job,"
        "InvocationID,Result,ExecMainCode,ExecMainStatus,ExecMainStartTimestampMonotonic,"
        "ExecStart,ExecStartPre,ExecStartPost,ExecCondition,FragmentPath,DropInPaths,NeedDaemonReload,NextElapseUSecRealtime,LastTriggerUSec"
    )
    result = dict(
        line.split("=", 1)
        for line in run(["/usr/bin/systemctl", "show", "--all", unit, "--property=" + fields]).decode().splitlines()
        if "=" in line
    )
    need(result.get("LoadState") == "loaded", "native unit unavailable")
    return result


def idle(row):
    return (
        row.get("ActiveState") in ("inactive", "failed")
        and row.get("MainPID") == row.get("ControlPID") == "0"
        and row.get("Job", "") in ("", "0")
    )


def tuple_snapshot():
    names = (RUNNER, RECEIPT, Path("/etc/systemd/system") / SERVICE, Path("/etc/systemd/system") / TIMER)
    return {str(p): digest(trusted(p)) for p in names}


def predecessor_bytes(value):
    hashes, payloads = value["previous_tuple"], value["previous_bytes"]
    need(set(hashes) == set(payloads) == set(value["target_tuple"]), "predecessor payload set differs")
    decoded = {name: base64.b64decode(raw, validate=True) for name, raw in payloads.items()}
    need(all(digest(raw) == hashes[name] for name, raw in decoded.items()), "predecessor payload hash differs")
    need(re.fullmatch("[0-9a-f]{40}", value["previous_revision"]), "predecessor revision malformed")
    need(decoded[str(RECEIPT)] == (value["previous_revision"] + "\n").encode(), "predecessor receipt differs")
    return decoded


def restore_predecessor(path, value):
    """Recover an interrupted installed tuple without enabling an old observer."""
    previous = predecessor_bytes(value)
    actual = tuple_snapshot()
    need(
        all(actual[name] in (value["previous_tuple"][name], value["target_tuple"][name]) for name in actual),
        "installed tuple contains unknown bytes; native rollback refused",
    )
    record(path, value, "ABORT_RESTORING", before=actual)
    # Publish the predecessor receipt first. The native interrupted-transaction
    # gate permits old/new member mixtures under an old receipt, but correctly
    # requires a complete new tuple whenever its new receipt is present.
    for name in [str(RECEIPT), *(name for name in previous if name != str(RECEIPT))]:
        raw = previous[name]
        target = Path(name)
        mode = 0o700 if target == RUNNER else 0o600 if target == RECEIPT else 0o644
        fd, temporary = tempfile.mkstemp(prefix=".hy2-rollback-", dir=target.parent)
        try:
            with os.fdopen(fd, "wb") as stream:
                os.fchmod(stream.fileno(), mode)
                stream.write(raw)
                stream.flush()
                os.fsync(stream.fileno())
            os.replace(temporary, target)
            directory_fd = os.open(target.parent, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW)
            try:
                os.fsync(directory_fd)
            finally:
                os.close(directory_fd)
        finally:
            if os.path.exists(temporary):
                os.unlink(temporary)
    run(["/usr/bin/systemctl", "daemon-reload"])
    effective_tuple()
    need(tuple_snapshot() == value["previous_tuple"], "predecessor tuple restore incomplete")


def effective_tuple():
    service, timer = show(SERVICE), show(TIMER)
    argv = (
        "/usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin HOME=/root LC_ALL=C "
        "/bin/bash --noprofile --norc -p " + str(RUNNER)
    )
    need(
        service.get("ExecStart", "").startswith("{ path=/usr/bin/env ; argv[]=" + argv + " ; ")
        and service["ExecStart"].count("{ path=") == 1
        and all(service.get(k, "") == "" for k in ("ExecStartPre", "ExecStartPost", "ExecCondition")),
        "effective native verifier command differs",
    )
    for name, row in ((SERVICE, service), (TIMER, timer)):
        need(
            row.get("FragmentPath") == "/etc/systemd/system/" + name
            and row.get("DropInPaths", "") == ""
            and row.get("NeedDaemonReload") == "no",
            "effective native unit differs from installed tuple",

def expected_tuple(root, revision):

def save(path, value):
    trusted(PARENT, directory=True)
    fd, name = tempfile.mkstemp(prefix=".upgrade-", dir=PARENT)
    try:
        with os.fdopen(fd, "wb") as stream:
            stream.write(canon(value))
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(name, path)
        fd = os.open(PARENT, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW)
        try:
            os.fsync(fd)
        finally:
            os.close(fd)
    finally:
        if os.path.exists(name):
            os.unlink(name)


def record(path, value, phase, **detail):
    value["phase"] = phase
    value["events"].append({"phase": phase, "at": time.time(), **detail})
    need(len(value["events"]) <= 256, "upgrade event budget exhausted")
    save(path, value)


def drain():
    deadline = time.monotonic() + BUDGET
    while True:
        row = show(SERVICE)
        if idle(row):
            return row
        need(time.monotonic() < deadline, "existing verifier still running; no process was stopped")
        time.sleep(1)


def verify_native(path, value, label):
    """Retain the same actual Invocation across controller interruption."""
    launch = value.get(label)
    if launch is not None and launch.get("result", {}).get("Result") not in (None, "success"):
        # An explicit later invocation may retry a proven terminal failure after
        # repair. Never replay a running/unknown launch, and retain every failure.
        row = show(SERVICE)
        need(
            idle(row) and row.get("InvocationID") == launch["invocation"],
            "failed verification no longer the actual native invocation",
        )
        value.setdefault("verification_history", []).append({"kind": label, **launch})
        need(len(value["verification_history"]) <= 16, "verification retry budget exceeded")
        del value[label]
        save(path, value)
        launch = None
    if launch is None:
        before = drain()
        value[label] = launch = {
            "before": before.get("InvocationID", ""),
            "started_at": time.time(),
            "invocation": None,
        }
        record(path, value, value["phase"], native_launch=label)
        # A lost command result is resolved from the unit below, never reset-failed.
        run(["/usr/bin/systemctl", "start", "--no-block", SERVICE])
    deadline = time.monotonic() + BUDGET
    while True:
        row = show(SERVICE)
        invocation = row.get("InvocationID", "")
        if invocation and invocation != launch["before"]:
            need(re.fullmatch("[0-9a-f]{32}", invocation), "native invocation malformed")
            if launch["invocation"] is None:
                launch["invocation"] = invocation
                save(path, value)
            need(launch["invocation"] == invocation, "native invocation changed")
            if idle(row):
                launch["result"] = row
                save(path, value)
                need(
                    row.get("Result") == "success"
                    and row.get("ExecMainStatus") == "0"
                    and row.get("ExecMainCode") == "1",
                    "actual native verifier failed; timer remains paused",
                )
                return row
        need(time.monotonic() < deadline, "native verification unknown; resume the same evidence")
        time.sleep(1)


def restore(path, value, terminal):
    wanted = value["original_timer"]
    need(
        wanted["UnitFileState"] == "enabled" and wanted["ActiveState"] == "active",
        "unsupported original timer lifecycle",
    )
    run(["/usr/bin/systemctl", "enable", "--now", TIMER])
    deadline = time.monotonic() + BUDGET
    while True:
        current, service = show(TIMER), show(SERVICE)
        need(
            current.get("UnitFileState") == "enabled" and current.get("ActiveState") == "active",
            "timer restoration lifecycle differs",
        )
        # While a Persistent catch-up service is running systemd can expose no
        # NextElapse yet. Observe its actual completion instead of calling that
        # transient state unschedulable or suppressing the catch-up.
        if idle(service) and current.get("NextElapseUSecRealtime") not in (None, "", "n/a", "infinity"):
            value["restoration_observed"] = {"timer": current, "service": service}
            save(path, value)
            need(
                service.get("Result") == "success" and service.get("ExecMainStatus") == "0",
                "restored native catch-up failed; result retained",
            )
            break
        need(time.monotonic() < deadline, "timer catch-up completion unknown; resume same receipt")
        time.sleep(1)
    record(path, value, terminal, restored_timer=current, catchup=service)


def failed_predecessor(row, invocation):
    """An explicitly named terminal exit may be repaired, never erased."""
    need(
        re.fullmatch("[0-9a-f]{32}", invocation)
        and row.get("InvocationID") == invocation
        and idle(row)
        and row.get("ActiveState") == row.get("SubState") == "failed"
        and row.get("Result") == "exit-code"
        and row.get("ExecMainCode") == "1"
        and row.get("ExecMainStatus", "0").isdigit()
        and int(row["ExecMainStatus"]) > 0,
        "explicit failed predecessor is not the current terminal exit",
    )


def retain_failed_predecessor(row, invocation):
    failed_predecessor(row, invocation)
    run(["/usr/bin/journalctl", "--sync"])
    raw = run(["/usr/bin/journalctl", "--no-pager", "--output=json", "_SYSTEMD_INVOCATION_ID=" + invocation])
    need(len(raw) <= 512 * 1024, "failed predecessor journal exceeds retained receipt budget")
    rows = [json.loads(line) for line in raw.splitlines()]
    need(
        rows and all(item.get("_SYSTEMD_INVOCATION_ID") == invocation for item in rows),
        "failed predecessor journal missing or unrelated",
    )
    need(show(SERVICE) == row, "failed predecessor changed during journal capture")
    return {"invocation": invocation, "sha256": digest(raw), "journal": base64.b64encode(raw).decode("ascii")}


def load_receipt(path, revision, target):
    raw = trusted(path)
    need(stat.S_IMODE(path.stat().st_mode) == 0o600, "upgrade receipt mode")
    value = json.loads(raw)
    need(
        canon(value) == raw
        and value["schema"] == 1
        and value["revision"] == revision
        and value["target_tuple"] == target,
        "upgrade receipt/source mismatch",
    )
    predecessor_bytes(value)
    return value


def supersede(path, revision, root, target, stale):
    """Rebind a PAUSED window, retaining its authenticated rollback evidence.

    The outer signed converger proves both the stale signed ancestry and the
    complete installed predecessor before calling this under the lifecycle lock.
    Tombstone the old window first: a crash can leave no new window, never two
    usable ones. Repeating this exact supersession completes that publication.
    """
    need(re.fullmatch("[0-9a-f]{40}", stale) and stale != revision, "invalid stale revision")
    old_path = PARENT / (stale + ".json")
    old_target = {str(RECEIPT): digest((stale + "\n").encode())}
    for name, relative in (
        (RUNNER, "scripts/run-signed-hy2-relay-dnat.sh"),
        (Path("/etc/systemd/system") / SERVICE, "scripts/" + SERVICE),
        (Path("/etc/systemd/system") / TIMER, "scripts/" + TIMER),
    ):
        old_target[str(name)] = digest(
            run(
                [
                    "/usr/bin/env",
                    "GIT_CONFIG_GLOBAL=/dev/null",
                    "GIT_CONFIG_SYSTEM=/dev/null",
                    "GIT_CONFIG_NOSYSTEM=1",
                    "/usr/bin/git",
                    "--no-pager",
                    "--no-replace-objects",
                    "-c",
                    "core.fsmonitor=false",
                    "-c",
                    "core.hooksPath=/dev/null",
                    "--git-dir=" + str(root / ".git"),
                    "--work-tree=" + str(root),
                    "show",
                    stale + ":" + relative,
                ]
            )
        )
    value = load_receipt(old_path, stale, old_target)
    binding = {"revision": revision, "target_tuple": target}
    need(
        value["phase"] == "PAUSED" or (value["phase"] == "SUPERSEDED" and value.get("successor") == binding),
        "only a paused window or its exact interrupted supersession is admissible",
    )
    need(not path.exists() and not path.is_symlink(), "successor already exists; resume with --apply")
    timer, service = show(TIMER), show(SERVICE)
    need(
        timer.get("UnitFileState") == "disabled"
        and timer.get("ActiveState") == "inactive"
        and timer.get("Job", "") in ("", "0")
        and idle(service),
        "supersede requires disabled inactive timer and idle service",
    )
    need(tuple_snapshot() == value["previous_tuple"], "paused predecessor changed")
    need(
        value["original_timer"].get("UnitFileState") == "enabled"
        and value["original_timer"].get("ActiveState") == "active",
        "unsupported original timer lifecycle",
    )
    successor = {
        key: value[key]
        for key in (
            "schema",
            "previous_revision",
            "previous_tuple",
            "previous_bytes",
            "original_timer",
            "original_service",
        )
    }
    if "failed_predecessor" in value:
        successor["failed_predecessor"] = value["failed_predecessor"]
    if value["phase"] == "PAUSED":
        value["successor"] = binding
        record(old_path, value, "SUPERSEDED", successor=revision)
    successor.update(
        revision=revision,
        target_tuple=target,
        events=[],
        supersedes={
            "revision": stale,
            "sha256": digest(trusted(old_path)),
        },
    )
    record(path, successor, "PAUSED", superseded=stale, paused_timer=timer, drained_service=service)


def operate(action, revision, root, failed_invocation="", supersedes=""):
    need(os.geteuid() == 0 and re.fullmatch("[0-9a-f]{40}", revision), "root/exact revision required")
    need(not failed_invocation or action == "prepare", "failed predecessor pin only applies to prepare")
    need(not supersedes or action == "supersede", "stale revision pin only applies to supersede")
    need(root == Path("/var/lib/yueops-release-roots") / revision, "canonical root required")
    if not PARENT.exists():
        need(action == "prepare", "no native upgrade receipt")
        PARENT.mkdir(mode=0o700)
        directory_fd = os.open(PARENT.parent, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW)
        try:
            os.fsync(directory_fd)
        finally:
            os.close(directory_fd)
    trusted(PARENT, directory=True)
    need(stat.S_IMODE(PARENT.stat().st_mode) == 0o700, "upgrade evidence directory mode")
    path = PARENT / (revision + ".json")
    target = expected_tuple(root, revision)
    effective_tuple()
    if action == "supersede":
        supersede(path, revision, root, target, supersedes)
        print("PAUSED")
        return
    if path.exists() or path.is_symlink():
        value = load_receipt(path, revision, target)
        need(value["phase"] != "SUPERSEDED", "superseded window is terminal; use its successor")
    else:
        need(action == "prepare", "no native upgrade receipt")
        timer, service = show(TIMER), show(SERVICE)
        need(
            timer.get("UnitFileState") == "enabled" and timer.get("ActiveState") == "active",
            "prepare requires original enabled active timer",
        )
        failed = None
        if failed_invocation:
            failed = retain_failed_predecessor(service, failed_invocation)
        else:
            need(
                service.get("ActiveState") != "failed",
                "existing failed verifier retained; exact invocation pin required",
            )
        value = dict(
            schema=1,
            revision=revision,
            target_tuple=target,
            previous_tuple=tuple_snapshot(),
            previous_bytes={name: base64.b64encode(trusted(Path(name))).decode("ascii") for name in tuple_snapshot()},
            previous_revision=trusted(RECEIPT).decode().strip(),
            original_timer=timer,
            original_service=service,
            events=[],
        )
        if failed is not None:
            value["failed_predecessor"] = failed
        record(path, value, "PREPARING")
    predecessor_bytes(value)
    phase = value["phase"]
    if action == "prepare":
        need(phase in ("PREPARING", "PAUSED"), "upgrade already advanced")
        need(tuple_snapshot() == value["previous_tuple"], "predecessor tuple changed")
        retained = value.get("failed_predecessor")
        need((retained or {}).get("invocation", "") == failed_invocation, "failed predecessor pin changed")
        if retained is not None:
            raw = base64.b64decode(retained["journal"], validate=True)
            need(digest(raw) == retained["sha256"], "retained failure journal differs")
            failed_predecessor(show(SERVICE), failed_invocation)
        run(["/usr/bin/systemctl", "disable", "--now", TIMER])
        row = drain()
        if retained is not None:
            failed_predecessor(row, failed_invocation)
        else:
            need(
                row.get("ActiveState") == "inactive" and row.get("Result") == "success",
                "existing verifier failed during natural drain; evidence retained",
            )
        timer = show(TIMER)
        need(
            timer.get("ActiveState") == "inactive" and timer.get("UnitFileState") == "disabled",
            "native upgrade timer was not durably disabled",
        )
        record(path, value, "PAUSED", drained_service=row, paused_timer=timer)
    elif action == "admit":
        need(
            phase in ("PAUSED", "INSTALLING", "VERIFYING", "VERIFIED", "FAILED", "COMPLETE"),
            "upgrade phase not admissible",
        )
        if phase == "COMPLETE":
            need(
                tuple_snapshot() == target
                and show(TIMER).get("ActiveState") == "active"
                and show(SERVICE).get("ActiveState") != "failed",
                "completed upgrade no longer current",
            )
            print("COMPLETE")
            return
        if phase == "VERIFIED":
            need(tuple_snapshot() == target, "verified upgrade tuple changed")
            print("VERIFIED")
            return
        timer, service = show(TIMER), drain()
        need(
            timer.get("ActiveState") == "inactive"
            and timer.get("UnitFileState") in ("enabled", "disabled")
            and idle(service),
            "upgrade timer/service must be naturally drained",
        )
        if phase == "PAUSED":
            need(tuple_snapshot() == value["previous_tuple"], "paused predecessor changed")
        if phase == "FAILED" and value.get("new_verification", {}).get("result") is not None:
            value.setdefault("verification_history", []).append(
                {"kind": "new_verification", **value.pop("new_verification")}
            )
            need(len(value["verification_history"]) <= 16, "verification retry budget exceeded")
        record(path, value, "INSTALLING", admitted_service=service)
    elif action == "verify":
        need(phase in ("INSTALLING", "VERIFYING", "FAILED"), "upgrade was not admitted")
        need(tuple_snapshot() == target, "installed target tuple not exact")
        need(show(TIMER).get("ActiveState") == "inactive", "timer ran before target proof")
        record(path, value, "VERIFYING")
        verify_native(path, value, "new_verification")
        need(tuple_snapshot() == target, "target changed during native verification")
        record(path, value, "VERIFIED")
    elif action == "finish":
        need(phase in ("VERIFIED", "COMPLETE"), "new verifier has not actually succeeded")
        need(tuple_snapshot() == target, "target tuple changed before restoration")
        restore(path, value, "COMPLETE")
    elif action == "abort":
        need(phase not in ("COMPLETE", "ABORTED"), "terminal upgrade cannot abort")
        need(show(TIMER).get("ActiveState") == "inactive", "old timer must remain paused")
        need(idle(drain()), "old verification must naturally drain")
        restore_predecessor(path, value)
        record(path, value, "ABORTING")
        # Real old verifier success proves all predecessor packages/protocols,
        # never merely a dpkg label or a locally manufactured rollback flag.
        verify_native(path, value, "old_verification")
        need(tuple_snapshot() == value["previous_tuple"], "old tuple changed during rollback proof")
        restore(path, value, "ABORTED")
    elif action == "failed":
        record(path, value, "FAILED", service=show(SERVICE), timer=show(TIMER))
    else:
        raise RuntimeError("unknown upgrade action")
    print(value["phase"])


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("action", choices=("prepare", "admit", "verify", "finish", "abort", "failed", "supersede"))
    parser.add_argument("revision")
    parser.add_argument("root", type=Path)
    parser.add_argument("--failed-invocation", default="")
    parser.add_argument("--supersedes", default="")
    args = parser.parse_args()
    operate(args.action, args.revision, args.root, args.failed_invocation, args.supersedes)


if __name__ == "__main__":
    main()

root_owned_no022_path() {
  local cursor=$1 mode
  [[ "$cursor" == /* ]] || return 1
  while :; do
    [[ ! -L "$cursor" && $(/usr/bin/stat -Lc '%u:%g' "$cursor" 2>/dev/null) == 0:0 ]] ||
      return 1
    mode=$(/usr/bin/stat -Lc '%a' "$cursor") || return 1
    (( (8#$mode & 8#022) == 0 )) || return 1
    [[ "$cursor" == / ]] && break
    cursor=${cursor%/*}; [[ -n "$cursor" ]] || cursor=/
  done
}
safe_pool_fqdn() {
  local value=$1 label
  local -a labels=()
  [[ ${#value} -le 253 &&
     "$value" =~ ^[A-Za-z0-9][A-Za-z0-9.-]{0,251}[A-Za-z0-9]$ ]] || return 1
  IFS=. read -r -a labels <<EOF
$value
EOF
  (( ${#labels[@]} >= 2 )) || return 1
  for label in "${labels[@]}"; do
    [[ "$label" =~ ^[A-Za-z0-9]([A-Za-z0-9-]{0,61}[A-Za-z0-9])?$ ]] ||
      return 1
  done
}
read_entry_pools_file() {
  local path=$1 size value
  local -a lines=()
  [[ -f "$path" && ! -L "$path" &&
     $(/usr/bin/stat -c '%u:%g:%a:%h' "$path") == 0:0:600:1 ]] || return 1
  root_owned_no022_path "$path" || return 1
  mapfile -t lines <"$path" 2>/dev/null || return 1
  [[ ${#lines[@]} -eq 1 &&
     "${lines[0]}" =~ ^V4_RELAY_PUBLIC_NAME=(.+)$ ]] || return 1
  value=${BASH_REMATCH[1]}
  safe_pool_fqdn "$value" || return 1
  size=$(/usr/bin/stat -c '%s' "$path") || return 1
  (( size == ${#lines[0]} + 1 )) || return 1
  printf '%s\n' "$value"
}
read_legacy_pool_dropin() {
  local path=$1 size value
  local -a lines=()
  # systemd drop-ins are public configuration and the historical writer
  # installed this exact file root:root 0644.  Requiring 0600 here made the
  # one-time migrator reject the only production predecessor it must consume.
  [[ -f "$path" && ! -L "$path" &&
     $(/usr/bin/stat -c '%u:%g:%a:%h' "$path") == 0:0:644:1 ]] || return 1
  root_owned_no022_path "$path" || return 1
  mapfile -t lines <"$path" 2>/dev/null || return 1
  [[ ${#lines[@]} -eq 2 && "${lines[0]}" == '[Service]' &&
     "${lines[1]}" =~ ^Environment=V4_RELAY_PUBLIC_NAME=(.+)$ ]] || return 1
  value=${BASH_REMATCH[1]}
  safe_pool_fqdn "$value" || return 1
  size=$(/usr/bin/stat -c '%s' "$path") || return 1
  (( size == ${#lines[0]} + ${#lines[1]} + 2 )) || return 1
  printf '%s\n' "$value"
}

def load_verifier(path, expected):
    flags = os.O_RDONLY | os.O_NONBLOCK | getattr(os, "O_NOFOLLOW", 0) | getattr(os, "O_CLOEXEC", 0)
    descriptor = os.open(path, flags)
    try:
        metadata = os.fstat(descriptor)
        if (not stat.S_ISREG(metadata.st_mode) or metadata.st_uid != 0 or metadata.st_gid != 0
                or stat.S_IMODE(metadata.st_mode) & 0o022 or metadata.st_nlink != 1
                or metadata.st_size > 1024 * 1024):
            raise ProofError("verifier metadata is unsafe")
        chunks, offset = [], 0
        while offset < metadata.st_size:
            chunk = os.pread(descriptor, min(1024 * 1024, metadata.st_size - offset), offset)
            if not chunk:
                raise ProofError("short verifier read")
            chunks.append(chunk)
            offset += len(chunk)
        payload = b"".join(chunks)
        if hashlib.sha256(payload).hexdigest() != expected:
            raise ProofError("verifier does not match its pinned SHA-256")
    finally:
        os.close(descriptor)
    module = types.ModuleType("yueops_pinned_release_root_verifier")
    module.__file__ = path
    sys.modules[module.__name__] = module
    exec(compile(payload, path, "exec"), module.__dict__)
    return module


def prove(verifier, git, revision, previous, signer, pairs, *, ancestry_only=False, uid=0, gid=0):
    """Prove installed ``pairs`` came from a signed ancestor of ``revision``."""
    if not REVISION.fullmatch(revision) or not REVISION.fullmatch(previous):
        raise ProofError("revision is not one full lowercase commit id")
    if previous == revision:
        raise ProofError("rootless predecessor cannot be the current revision")
    if ancestry_only == bool(pairs):
        raise ProofError("pairs are required unless ancestry-only was requested")
    head = verifier._one_line(git.run("rev-parse", "--verify", "HEAD^{commit}"), "HEAD")
    if head != revision:
        raise ProofError("current release HEAD is not the requested revision")
    resolved = verifier._one_line(
        git.run("rev-parse", "--verify", f"{previous}^{{commit}}"), "previous"
    )
    if resolved != previous:
        raise ProofError("predecessor is not one exact commit")
    ancestry = git.status("merge-base", "--is-ancestor", previous, revision)
    if ancestry == 1:
        raise ProofError("predecessor is not an ancestor of the current revision")
    if ancestry != 0:
        raise ProofError("predecessor ancestry is unproven")
    verifier._verify_signature(git, previous, signer)
    seen = set()
    for relative, target in pairs:
        if not RELATIVE.fullmatch(relative) or ".." in relative.split("/") or relative in seen:
            raise ProofError(f"invalid predecessor path: {relative}")
        if not os.path.isabs(target):
            raise ProofError(f"installed target is not absolute: {target}")
        seen.add(relative)
        row = git.run("ls-tree", "-z", previous, "--", relative)
        prefix, separator, named = row.partition(b"\t")
        fields = prefix.split()
        if (separator != b"\t" or named != os.fsencode(relative) + b"\0" or len(fields) != 3
                or fields[0] not in (b"100644", b"100755") or fields[1] != b"blob"):
            raise ProofError(f"predecessor tree lacks a regular file: {relative}")
        expected = git.run("cat-file", "blob", fields[2].decode("ascii"))
        installed = verifier.stable_regular_bytes(
            verifier.Path(target), expected_uid=uid, expected_gid=gid
        )
        if installed != expected:
            raise ProofError(f"installed bytes differ from signed predecessor: {relative}")
    # Signature again after the byte reads, mirroring verify_release.
    verifier._verify_signature(git, previous, signer)


def parse_pairs(arguments):
    if arguments == ["--ancestry-only"]:
        return [], True
    pairs = []
    for argument in arguments:
        relative, separator, target = argument.partition("=")
        if separator != "=" or not relative or not target:
            raise ProofError("pair is not relative=target")
        pairs.append((relative, target))
    return pairs, False
